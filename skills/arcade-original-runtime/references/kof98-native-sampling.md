# KOF98 原版采样的实测条件

仅适用于当前 MAME0.289 / KOF98 原版 ROM；不把这些 tick 数推广为其他作品的输入阈值。详见项目 `tools/attack-library/data/research/kof98-{actions,author,meter,edges}-20261016/` 的实际 source.lua、输入、trace、截图与失败收据。

- 每个动作组开新局，菜单证明人物和 ADV/EXTRA 模式。选择过渡会吞键；EXTRA 的成功时序要以绿色 EX 标志核对，不能以发送 Down 就当成功。
- 超杀先用普通 ABC 自然蓄满；低血条件由 P2 普通攻击造成。草薙京大蛇薙可用作超杀链条的已知成功对照。双236原来退化普通攻击；在两个236之间放3原生刷新中立，原画中出现黑闪、无式蓄火和连击。这个时序经过了同状态机复测。
- 不以低血意图自动签 SDM：红丸 HP19 的原画仍是蓝闪普通DM；HP9 的对照才出现橙色闪光/金橙雷球和不同连击。普通/MAX标签必须同时保留实际HP、气槽、原图差异和具体角色证据。
- Down 与攻击同帧短按可能得到站立攻击。扫倒改为 P2 先保持 Down15tick，再D；东丈原画中才出现命中、横躺、起身。倒地采样须看这三段，HP变化不够。
- 对手穿越造成转身应用 P2 从近身跳过站定P1；向前走无法穿过碰撞体，不能把它签为转身成功。前后跃过时可能改变 facing，方向输入记录保留原始端口而不是事后改名。
- 生命字节在KO后可能为251/255等值；零值单一哨兵会漏判。阈值只用于停止保护，不代替KO视觉证据。KO后+120/+300可能仍停在 PERFECT，+500探针才取得部分角色胜利姿势；保留不足窗口。
- 原作者PDF跨行需要整页看图：Terry Power Charge 的41236曾被拆到无名行；Leona Gliding Buster 的 Ground Saber D、Kim Ten Sou Zan 的 Hi En Zan D 是前置条件，不是额外招式。
- 并行采集必须隔离目录、单batch锁与唯一原子临时文件。恢复只跳过有完整有效收据的批次；SIGTERM可能被模拟器当正常退出，需检查CSV schema、tick/screenFrame连续、PNG数量和320×224尺寸。

数量分开记录：输入候选、连续原画窗口、触发已观察、逐招验收、透明精灵恢复、判定/战斗逻辑。中立和准备窗口不是额外招式；普通与失败版本不能叠加成完成率。

ADV界面蓝色“1 ADV”是模式标志，不代表已有1stock；本次只读0x1082E3由普通出招真实攒到1/2后才具备取消条件。防御取消需同时观察蓝防御圆、stock1→0和取消姿势/轨迹。东丈前AB源门用守架后松方向的默认AB；强塞前方向曾只触发普通滚动。推广后Vice/Iori/Daimon同一前AB配方仍未触发，不把源门成功扩大为16人通过。Daimon623C为佯攻未积气，623A实地震配普通P2跳跃后可自然攒气；这类角色变体差异需由实际气槽变化确认。
