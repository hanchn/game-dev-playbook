# 游戏技能特效库

优先接成熟作者的完整原工程、纹理、模型、材质和原运行时。保留固定版本、原SHA与编译输出收据；不能把手写基础粒子叫做下载成熟特效。

先看真实正常/慢速播放和峰值，再判断资源是否符合用户风格。风格化火环、卡通烟爆、写实模拟分开；资源多不能代替画质。下载、编译、运行可见、美术通过、游戏可用分别记录。教学/投影/皮肤不重复计数为攻击技能。

Effekseer接入须使用匹配WASM，原依赖目录与材质保持完整。旧ZIP非UTF8文件名要依据源编码修正名称映射，不改纹理字节。实例预算耗尽即使有画面也算技术未过。当前库只有原生显示，不自动等于HDR、美术、碰撞或性能通过。

角色演出检查抬手蓄力、释放、飞行/范围、命中、受击、余波与音效时序；特效不能在收手以后才开始。以真实骨挂点跟随；原模型没有Cast就明确派生，不把其他运动clip冒称施法。

按实际最大范围/峰值设置相机，避免裁切和远看成小点。确定时刻拖动需真实运行时模拟；句柄存在不等于画面绘制。支持反向拖动时复位实例/随机种子并复测，不积累上轮状态。

Three共享GL绘制按原运行时要求更新/设置相机/捕捉背景，绘制后恢复渲染状态。记录CPU调用、异步GPU、整帧耗时各自范围；扩大粒子预算不能称性能优化。

本项目入口 `/vfx-library`、`/vfx-library-quarks`、`/vfx-production`；原资源 `tools/animation-lab/public/vfx-assets/`，实际证据 `tools/animation-lab/examples/`。复用知识见 `tools/animation-lab/docs/vfx-production-2026-10-14.md` 和 `asset-library-maintenance-2026-10-15.md`。

2D招式必须让实际2D角色出手与受击，不能只把3D效果换正交投影。先统一角色、武器、地面与效果的像素密度、画风和光照；用户拒收的混搭保留失败版本，不以增加数量掩盖。角色序列与武器图集可能为64/128/192不同格距，必须分别注册中心与前后层。攻击效果须核对真实出手时刻及近战距离，禁止先出现命中再挥武器。新入口 `/combat-2d`、原像素参考 `/pixel-combat`；参考图集带非整格边缘时列数取整并验证索引。原始资源、适配播放与游戏碰撞分别登记，详见 `docs/combat-2d-2026-10-15.md`。


## 二维分层序列特效实测

以角色与透明FX分别保留原始画布。实际读取生成图尺寸，按明确4×3规则切片，检查每格核心与透明padding，记录核心pivot、掌心/释放锚点和身体时槽mapping。演出可统一扩展场景画布容纳飞行，保持身体worldScale，不按每帧bbox缩放。实际播放用了哪些爆散源要诚实记录，不把未播放源计为已展示。

独立演出验正常/慢速、深浅底、蓄力掌间、离掌、飞行、爆点与结束清除；反向逐帧必须直接复现对应状态，切动作取消旧RAF。仅展示位置的爆点不算目标碰撞或伤害时序通过。逐像素图集审计区分可见RGBA差异与alpha为零的隐藏RGB差异，后者不直接判视觉错帧。
