# 实际验收

在目标手机、平板、横竖屏显示大小检查一次完整入口、游玩、图鉴、解锁和结算流程。构建通过只证明代码可打包，不证明动画自然。

- 主体：首尾循环自然，朝向与移动一致，长尾/触须完整；同动作固定尺度，跨动作头宽及人物比例一致，载具底盘没有重复或压扁。
- UI：图案等比、四边完整、文字落在空槽，热区可触达；safe area不压内容。图鉴切卡先移动后换层，所有卡都可到达且未解锁状态正确。
- 入口：缓存冷/热两次启动，加载位置一致且仅一条进度；图片解码和首次绘制完成后才显示场景，没有图标、投影或动物在左上角闪现。
- 生命周期：出画主体、投影、碰撞一起回收；覆盖界面后游戏计时和背景角色暂停。HUD在数值不变时不重建DOM，不运行不可见卡动画。
- 性能：记录修改前后同场景的FPS、CPU更新时间、存活/可见实体和纹理量。用实际全部存活对象衡量预算，包含装饰与投影，不能只计鱼或动物。
- 交付：保留原图、未用资产和来源，记录实际看过的动作与尚未验证的部分，按项目要求提交保存。

## 两次项目中的经验边界

捕鱼高手验证过完整按钮边缘、固定船体尺度、图鉴层序、开始按钮槽位加载、数字复用与回收投影。这些方法可复用。该项目的海面消失线、鱼价、20实体上限不是其他游戏的默认规则。

外星农场采用固定敞篷底盘与独立驾驶员动作，围栏替代鱼缸。它的负重、反击与逃脱概率是玩法设定；不能凭“类似捕鱼”自动复制海洋对象分布和扣费数值。
