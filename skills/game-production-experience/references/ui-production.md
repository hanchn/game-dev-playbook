# UI固定模板与出图

先画壳，再填内容。建立viewport与safe area、按钮/卡片外框的固定比例、内容槽位和交互区；可变标题、数字、说明、状态不烘焙进通用底图。首页海报可以含固定游戏标题，但复用面板应提供空槽。

用JSON/CSV记录 `path, sourceWidth, sourceHeight, bounds, aspect, safeMargin, slots, hitArea, provenance, status`。槽位用归一化坐标，明确标题、角色、正文、价格、按钮各区。运行时按同一模板定位，禁止为了填满槽位把素材非等比拉伸。

装饰复杂的按钮按完整原比例显示；九宫格只用于已设计可延展的中间区，不能横切贝壳、绳索、金属边框后拉伸导致接缝。交互热区可以大于可见图案，二者独立定义，手机触控不靠放大图案解决。

原图透明边要容纳投影、灯光和动作极值。原生SVG视口裁图只引用或嵌入原位图，不改变像素；浏览器作为img加载的SVG外链位图可能受限，需实际验证。不要以此代替修复源图已裁掉的尾巴。

图鉴是完整卡片堆叠：前卡、后卡、左右移动、层序重排分阶段执行，检查换层瞬间。容器不要用左右裁切模拟换卡。只有真实解锁的数据使卡片高亮；锁定卡的主体和装饰统一置灰并停止动画，不能借调试金币残留使高等级卡亮起。

加载入口沿已确认设计：若是开始按钮位替换，就保留海报，在同一槽显示进度轨道与沿轨移动的角色，不新增弹窗或第二条进度线。角色尺度与轨道对齐固定；进度来自真实就绪状态。
