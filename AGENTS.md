# Game development knowledge base

- Follow the explicit user workflow: implement one Epic, test it, capture reusable knowledge and failures, then commit and push the verified batch.
- Continue external resource acquisition and reverse engineering alongside game development; connect evidence to the active Epic.
- Record character production methods, exact source poses, native frame dimensions, alpha margins, pivots, offsets, timing, collision and state behavior.
- Distinguish original-game evidence, adaptations and reconstructed experiments. Do not call PNG poses recovered bones or experimental timing original frame data.
- Persist methods, sources, reproduction steps, limitations and verification status in the knowledge base. Keep private character images in the private game repository.
- Close an Epic only after its required implementation, tests, knowledge record and push are complete.
