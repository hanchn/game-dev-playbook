# 序列帧验收工具

从实际游戏的动画预览页提取的通用版，使用 Phaser 3 渲染。支持多个角色图集、时间播放、路程模拟、速度调整、暂停、前后逐帧、换向、深浅背景、完整帧网格，以及原比例图集重排导出。附只读 PNG 边界检查。

工具不带私有游戏素材。默认几何示例只是技术测试，不代表正确的动物步态；判断动作自然度请按 [步态经验](../../docs/sprite-gait.md) 执行。

## 启动

在本目录运行（需要 Node.js 18+）：

```sh
npm install
npm run dev
```

打开 `http://127.0.0.1:5176/`。默认只监听本机；此端口被占用时，以终端显示的实际地址为准。

## 载入自己项目的图集

1. 准备下方格式的 JSON，路径填图片文件名。
2. 在页面选择“配置 JSON”和对应“本机图集”，点击“载入配置与图片”。图片仅通过浏览器本机文件对象读取，工具没有上传接口。
3. 先看全部角色，选择单个角色后检查放大播放和所有源帧；逐帧按钮按 `playFrames` 的作者序列走，网格保留所有帧并标记未播放帧。
4. 用慢放、换向与深浅背景核对肢体身份、比例、遮挡、循环、透明边界。路程模式是模拟，真实游戏仍需检查实际位移与停步。

```json
{
  "characters": [{
    "id": "dog-walk",
    "name": "狗 · 行走",
    "path": "dog-walk.png",
    "grid": {
      "columns": 4, "rows": 2,
      "frameWidth": 512, "frameHeight": 512, "count": 8
    },
    "playFrames": [0, 1, 2, 3, 4, 5, 6, 7],
    "fps": 7,
    "direction": "right",
    "bodyWidth": 350,
    "originX": 0.5, "originY": 0.85,
    "stride": 120, "previewSpeed": 80,
    "minMargin": 8
  }]
}
```

上述数值仅演示字段，不是新项目默认要求。所有帧采用同一个逻辑画布，禁止逐帧归一化尺度。`bodyWidth` 用于预览的共同缩放；`stride` 和 `previewSpeed` 是同一坐标尺度下的单周期距离及每秒距离。

不等分排列时，用 `frames` 替代 `grid`，逐帧列出 `x`、`y`、`width`、`height`，可另填 `offsetX`、`offsetY`。偏移按源画布像素记录；工具按共同尺度平移，镜像时反转横向偏移。帧率也接受原项目的 `walkFps` 字段。此版本接受已打包图集，不接受一帧一文件或骨骼工程。

需要固定项目素材时，可把配置和图片放在 `public/local/`，在页面选择配置后载入；例如路径 `local/dog-walk.png`。该目录被忽略，避免误提交私有素材。HTTP 路径仅供本机服务读取，不能填写远程 URL。

## 导出

单角色模式分别点击“导出 PNG”和“导出配置”，页面生成图集预览及保存链接，再保存两份同名配套文件。PNG 按最多四列重新排列**完整源帧**，保持原比例；配置保留播放顺序、共同锚点及偏移。导出不修动作、不烘焙偏移、不改变原素材，也不会自动认可资产。超过设备纹理上限时应分组打包，不强制缩小或拉伸。

“重新预览导出”将生成的 PNG 和配套配置直接重新载入，便于核对导入导出一致性。若内置浏览器不支持保存链接，可在普通浏览器打开同一本机地址，或保存页面上的图集预览。

## 自动检查

PNG 检查只支持 8-bit RGBA、非隔行格式；SVG 示例仅用于浏览器预览。命令默认以配置所在目录作为图片根目录，也可明确指定：

```sh
npm run check -- /path/to/manifest.json /path/to/images
npm test
npm run build
```

检查图集矩形、每帧是否为空、透明安全边距及播放序列。alpha 大于 128 的像素计为主体；不同阈值下的淡光晕仍须视觉检查。失败返回非零，成功只代表技术边界通过。帧偏移后的接缝与运行裁切仍需在预览和游戏验证。

## 来源与边界

功能提取自 Phaser 游戏预览工具，去掉了角色名单、固定分辨率、固定导出缩放和私有资源依赖。保留候选、自动检查、逐帧视觉、游戏验证、用户反馈各自的记录，不能用测试通过替代动作验收。几何示例为本工具原创测试夹具；没有复制任何游戏原画或失败候选。
