# 圆弧零件与复杂动作制作

十类角色已有制作版本；人的视觉问题正在按逐关节流程修正，其他角色仍需按更新流程逐个复核。全部为正交侧面、朝右；俯拍、背面需要另外制作素材和遮挡关系。机器人零件的要求落实在平滑端部与旋转重叠区，角色外观保留自然皮肤、羽毛、鳞片、毛发和甲壳。

## 素材与绑定

1. 用内置 image_gen 重绘完整圆弧端部；平直横切断面和空心套筒无法靠提高帧数修复。保留失败候选，不覆盖已认可的骨架。人的原行走节点有回归快照。
2. 提示词明确近端、远端、源轴方向及槽位。头、脚爪保持朝右；爪指、下颌和尾刺按真实尖端定位，不能照搬其他部位的默认轴点。
3. `scripts/scan-atlas.mjs` 测量透明图的独立连通区域，以真实行列排序注册。生成图的间距和部件尺寸不一定等分；不得沿格子硬切肢体。
4. 零件矩形可能夹带邻件像素。渲染时使用该连通区域的带留边轮廓限制显示；源 PNG 不改像素。源图本身缺件、重复下颌或方向错误时重新出图。蛇 v2 的首行缺件及重复下颌、蚯蚓 v2 的首行缺件已修复为 v3。
5. 把轴点放在圆弧重叠区内，再按骨长求图像宽高和角度。远侧肢体先画，身体居中，近侧肢体后画。导出隐藏骨骼、轴点和选择标记。
6. 恐龙/鳄鱼长尾、百足虫/蛇/蚯蚓身体使用连续蒙皮；蛇/蚯蚓按原生部位拼接多张源素材，尾尖不能拉伸覆盖整身。骨链之间以平滑曲线插值，三角网格共享边界。蝎子的天然分节甲壳保留独立尾节。

## 骨骼与动作

- 人的蹲、弯腰、拳击使用稳定支撑脚与独立肩肘/髋膝姿势；跳跃有蓄力、腾空和落地缓冲，拳击使用闭拳素材。
- 四足保留前后腿和近远腿身份。马的四拍行走与对角快跑分别设相位，支撑足世界坐标固定，根运动单独导出。
- 百足虫十对腿沿身体延迟相位。蜘蛛与蝎子八条步足保留七节身份，逆运动学固定各节长度。
- 单件测试驱动选中关节，下游跟随，其他肢体固定。人的头颈必须活动检视；其他未做独立运动的静态件仅登记结构检查。
- 柔性动作是二维运动学。蛇的推进、蚯蚓的钻地和收缩没有地面摩擦/土壤动力学；不可把动作图集当作生物仿真证据。

## UI 检视经验

动作库显示独立时长与循环/单次标记。支持 0.25 倍慢放、逐帧、全身/关节检视和深浅/棋盘背景。预览保留已解码的图片节点，只更新变换和网格顶点，避免每帧重新创建图片造成短暂空白。

批量下载可能被浏览器限制。工作台提供“保存全部动作到项目”，直接把当前角色的 PNG、帧元数据、骨骼 JSON 和技术报告写到 `examples/<asset-id>/`。导出统一 512×512 帧，4×4 图集为 2048×2048，逐帧裁剪防止跨帧溢出。画布尺度和锚点固定，不以每帧可见边界重新缩放。

## 验收与复用

`npm test` 包含原型、人的原行走、复杂动作和生产角色回归；故障注入必须拒收同相、滑步、拉长、断环和静止腿。额外检查连续蒙皮共享边与贴图轴点的变换。

保存 PNG 后运行：

```sh
node scripts/export-evidence.mjs <species>
node scripts/verify-production.mjs <species> '实际视觉复核备注'
```

后者检查各完整动作、各活动关节、每帧透明边界，再保存 `production-review.json` 和知识记录。`public/art/<species>-source-prompt.json` 保存内置工具提示词、视角和失败版本原因，`skins.json` 保存实际区域和校准。自动通过与代理复核不等于用户已签署视觉验收。

本轮使用 imagegen、sprite-animation-production、game-ui-ux、game-feel、remember-project-requirements 的相关流程；通过 skill-creator 将已验证经验以项目案例纳入现有序列帧 skill，未引入无关的三维或 Figma 依赖。

## 人形逐关节修正案例

见 [人形贴图与关节衔接经验](human-joint-review.md)。源素材的部位归属、弯曲时相邻贴图、遮挡顺序和动作素材清单都须检查。先完整调好人，再扩展其他角色；技术检查、代理看图和用户认可分别记录。

换皮肤需保留原生比例并单独校准地标；正常不透明画面必须与内部淡化画面分开。当前动物仍有待复核的用户缺陷，旧版技术记录不表示最新美术通过。
