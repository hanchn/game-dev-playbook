# 角色资产与分层验收契约

## 已确定的产品要求

角色作为可复用、可版本化资产生产，从零件设计开始。流程为设计形象 → 结构拆分 → 组合成型 → 测试动作，零件在组装前就必须能够单独演示和检查。支持类似组装玩具的爆炸拆解与合并动作。不能只测完整角色动画。每类角色须保留详细动作设计。

首批：人；鸡、恐龙；马、鳄鱼；百足虫、蜘蛛、蝎子；蛇、蚯蚓。总体范围还包括序列帧生成与测试、FPS 曲线、骨骼动画生成与组装、MCP、UI 套件和知识沉淀。

## 资产层级

`asset → parts → assembly → clips → QA → knowledge`

- `id + version` 定位资产快照；`species` 指定结构契约。
- `parts[].id` 是身份，不随动作帧或拆解演示改变；近远侧身份与腿索引稳定。
- `parent` 表示装配父级。当前物种结构固定，编辑尺寸与层级不会改变连接拓扑。
- `rest` 为角色局部坐标。`dimensions` 为尺寸/骨长，不在播放中按包围盒缩放。
- 内部 pivot 作为动画计算位置，圆弧端部提供重叠区；允许同材质圆形/球形遮挡衔接核；自然外观不绘制机械插槽或卡接硬件。
- `range` 存储设计角度；首版腿链实际执行膝关节 155°上限，髋关节范围和其他部位角度尚未全量验证。
- `phase` 定义组间时序。个体接地规则与完整角色相位规则分开。
- `actionDesign` 描述姿势、时序、参与零件、接地关系、标准与限制。
- `source`、rendering.atlas、skins.json 和 source-prompt.json 保存生成来源、素材版本、视角、透明区域和轴点校准；原型来源另行保留。

## 三层测试

| 层级 | 测试对象 | 证据 |
| --- | --- | --- |
| 单配件 | 单腿链/单身体节段 | 收拢→伸展→收拢，连接不掉落，脚端确实运动，骨长稳定，循环连续 |
| 局部组合 | 选中零件及其子树 | 多连接连续，层级与身份稳定，局部动作不改变其他结构 |
| 完整角色 | 所有零件与统一步态 | 分组相位、支撑滑步、穿地、全角色循环与正常速度观看 |

两段腿的上段/下段/脚端任一被选中，检测完整所属腿链；独立运动保持父件和下游件可见、其他件固定且默认不透明，局部组合模式显示其链；淡化检视作为显式开关。人形头颈有独立运动；其余未提供独立动作的静态件，不把静态件的结构通过描述为动态验收通过。

无足资产单节检查只覆盖选中节段边界和长度，不证明地面摩擦、前进效率或土壤推进。序列帧生成保留固定画布、锚点、帧率和播放顺序；透明边界检查仍可用仓库已有 PNG 检查脚本。图集技术正确不等于动作自然。

## 验收与沉淀

每次保存重新检查，不能由调用者提交“通过”来覆盖结果。保存资产快照、动作、层级、部件、故障状态、检查详情、备注和时间。`technical-passed` 与 `rejected` 都能沉淀；`visualStatus` 始终保持 `pending`。当前没有人工签署 approved 功能。

## 当前实现与后续边界

已增加人的髋膝踝、肩肘腕复杂动作、双螯独立活动指、尾链/尾尖和连续身体蒙皮。每个活动关节都支持独立动作检查；角度极限与速度上限未全量验证。引擎适配、三维和人工签署仍待实现。先用代表配件验证再批量生成完整角色；不能用新增角色数量替代代表动作覆盖。
