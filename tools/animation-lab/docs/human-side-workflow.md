# 人的侧面资产：制作与调试记录

## 当前范围

本记录保留人的侧面调试经验；当前真人v17与外星人v6正在按美术QA流程复核；其余九类角色保留候选版本，见 [圆弧零件工作流](rounded-parts-workflow.md)。当前支持视角为 **正交侧面、朝右**；俯拍、背面需要单独制作贴图、绑定和遮挡层级。

## 发现的问题与处理方法

1. 设计图混合正面、俯视与斜视，不能直接当作侧面游戏零件。重新生成严格侧面图，资产、动作、帧元数据都保存 view / projection / facing。
2. “像玩具一样拆合”描述的是检视互动，不是角色外观。移除机械插槽、空心套筒和金属卡接外观；允许按用户要求使用同材质、隐藏的球形重叠核。骨骼轴点仅作为内部坐标；导出不绘制点或连线。
3. 零件不是按均分格子硬切。测量原始透明 alpha 的独立轮廓，记录原始图上的矩形，不修改原始像素。源图保留 16 个素材模块，组装实例含躯干、颈头和两侧肩肘腕/髋膝踝。
4. 直立人体的骨段素材沿竖直方向。按每块贴图自身近端/远端坐标求缩放和角度，不能把竖直手臂按横向骨段去旋转。轴点误差会产生脱节、缩短或旋转偏移。
5. 连接处采用自然贴图重叠，固定先远侧肢体、再身体、再近侧肢体的遮挡顺序。头部、躯干和腿长重新校准比例。
6. 单件测试只驱动所选关节，其子零件跟随，其他肢体固定。前臂测试不能被“整个人都动了”替代。足部测试同时检查旋转变化，避免只看轴点位置而误判静止。
7. 支撑脚固定在世界坐标，根运动独立导出。动画预览原地循环，摆动期抬脚回摆，左右腿相差半周期，手臂反向摆动。
8. 实时画面用同源 PNG URL；SVG 图集只内嵌一次源 PNG，帧用引用实例；PNG 用相同关节变换直接合成，避免每帧大量重复 base64 数据。

## 验证证据

- 14 个头颈及肢体衔接位独立动作：固定父轴、骨长、下游连接、循环和非选中肢体静止。
- 完整行走：骨长、关节连续、左右相位、支撑脚稳定、两腿回摆。
- 五类故障：同相、滑脚、骨段拉长、循环断裂、腿静止都被检测。
- 贴图轴点经坐标变换后与骨骼起止点逐帧重合。
- 浏览器导出的 PNG 为透明 2048×2048，4×4 共16帧，固定锚点 [256,350]。
- QA 的技术通过不包含对人体动作自然度、皮肤接缝质量及目标游戏观感的自动承诺。视觉状态保持待验收。
