# 动物源图与关节复测经验

每个源版本必须重新扫描 alpha 连通组件、独立小组件和低透明边缘。凸包只用于粗范围，不能当像素归属；旧恐龙头颈 crop 带入相邻身体像素，曾形成很明显的颈后尖刺。当前 source mask 是精确组件矩形并集，源 PNG 未经程序像素编辑。

骨架、素材与层级要同时校准。马前腕链和后飞节链不同；恐龙的髋→膝→踝→跖趾应遵循结构，不靠腿加粗遮裂缝。保持素材原生 aspect，圆头只提供旋转覆盖，不能用肉球和细杆冒充合理关节。

连续颈根需要源截面中心和实际身体遮挡。把整个头颈放在 body 前会出现羽毛围巾；只开启 neckUnderBody 也不够，颈 part 的绘制层必须小于 body。斜 UV 分层可保留前喉、藏后根，但根选在源截面的后边仍可能让前喉悬空。母鸡 v2→v3→v4 的失败与复测保留了这一区别。刚性颅面要用源点位置回归验证，不能为了接缝一起拉脸。

源脚底/喙端要通过实际 sourcePointWorld 求地面接触。近远素材下边界不同，统一足底偏移会浮脚。动作测试应识别接触和恢复阶段，啄食恢复段喙离地不属于缺陷。

QA 拍摄同时记录资产ID、源SHA、源绑定参数、共享renderer版本、时间/相位、背景、倍率和画布。原生固定画布用于包络、比例与接触，独立放大 contact sheet 只用于看接缝。工作台1.65倍近景会裁掉检视框外的足或嘴，不能代替导出包络测试。尚未打开观察的 PNG 不写成美术通过。

性能也要在真实浏览器测试。马头颈数千三角的 SVG 舞台和同步16帧SVG缩略图造成大DOM卡顿；现在舞台连续颈使用 Canvas，缩略图每个 RAF 绘一张，使用固定生产相机、source/asset快照及取消过时任务。浏览器累计 P95 含操作和首次批量渲染，不声称60FPS。Node bind 耗时和几何误差检查不能代替实际 UI。

生成新的张嘴中间头即使统一眼点和像素比例，也可能改变脸形。素材记录里明确“候选近似但未锁像素”，必须四态播放审身份；需要时只替换配准的喙材质区域，不能冒称全头无变化。

局部生图编辑也会改变未要求的部件边界与尺寸。母鸡腿源v3相较原v1，其余部件1～7px漂移；应只注册实际所需的两件到独立source，保持14件原PNG与绑定不变。每tile精确组件扫描必须读取它所属的atlas，测试旧主图不能证明alternate归属。缺图应报错，不默默回退。

深蹲后折叠关节可能回到躯干内部；将羽毛腿罩和鳞段整件画在体羽前会形成胸前黄斑和卵形贴垫。应以实际髋/膝世界坐标及源distal部位核对真实父躯干遮挡，同时把独立腿件在暴露角度、站起、行走和慢放审一遍；不能只用藏住错误来通过。母鸡v5失败与v6改进已保留同1.50/3.25/4.40s、双源SHA和正常不透明证据。

根代理独立复核 horse v20 `ui-graze-phase0467-canvas-light-detail.png`：肩后黑鬃根斜立如刀片、近肩骨段有卵状鼓包。性能改善与数值通过均不能覆盖这一源姿态美术失败。

## horse v23 新源与测试范围（当前失败）

- 独立mini atlas消费真实源native aspect并保骨长，能减少旧大块，但新源末端若带多余残桩/球帽，绑定到骨链仍会显出玩偶接缝；opaque源端点检查仅证明点在材质内，不证明解剖地标正确。
- `examples/horse-side-v23/retest/visual-review.json` 严格区分实际看过的光暗底/动作/部件；normal extend幅度±.40rad，与声明range诊断压力测试分开记。任意±100/120度不能冒称马自然关节验收。
- 四种颈根猜测都在同吃草`.467`保留折片，未注册；一项参数缩小局部突起不等于颈根连续解剖。
- 源图不变也会因neckMask或分层变更改变网格误差。当前refineTolerance .4实际max .34963rigpx失败，.2max .20383/最高1498tri通过原.25/4000阈值。真实UI折片未消失，数值与美术分开记录。
- 主图源蹄端的高光金属板状感应主动识别并留失败；不能因为本轮只替换上段而忽略其余实物源。

## 鸡局部源修复的验收范围（rooster5 / hen7）

完整atlas编辑会让未授权部位漂移，因此v4左羽毛件、v5右鳞杆件分开作为精确source。精确mask需按实际tileCount/rows和sourceTileIndex重扫，不可将原16件索引2/3直接用于两件mini atlas。其他14旧件字段和源SHA逐项锁定。羽毛胫段根归属body之后，必须用单件转动/正常站立暴露源轮廓证明合理，不能用坐窝遮挡替代源QA。新冠脖底本来不规则羽毛边，但renderer若在src.v做水平截断仍会在成片生成硬边。直观看原图与成片才能区分源问题和分层问题。当前63项技术通过，局部贴胸块改善，整体仍failed；actual paths见examples/chicken-leg-source-v5/visual-review.json。

### 马颈路径候选与失败精度（2026-10-12）

根截面按躯干方向锁定适合部分衣领，却不能自动作为马低头时的解剖路径。实际 horse v24 源颈线在固定 body 根切线下形成高曲率急弯；中心线保宽不等于自然形体。离线 body-tangent 候选 mesh 源点误差 1.10 rigpx，必须保留失败，不放宽原 .25 阈值。源根/颅颈端截面处分别切三角形，连续源曲线与实际 neck 骨方向后，5×16相位实际源点诊断 .07453 rigpx / 2548 triangles；仍须看十张深浅整动作联系图。下颌块、鬃边台阶及腿比例/结节仍失败。数学保宽仅适用未进入 face guard 混合的截面，不能宣传为全源零形变；轴向伸长率另行记录。

### 浏览器候选与电影 QA 的边界

实际马颈诊断页已完成五动作各16次逐帧操作、五套32PNG包、正常/.25倍十段实际视频；真实源快照与每帧 SHA 全部保存。所有最新接触图看过仍美术失败，正常6FPS/慢速7FPS也仍性能失败。源点误差、缓存测试和视频帧数通过不能覆盖身体比例、吃草支撑、动作力度或完整帧率。

同一局部 Canvas 绘制在外层平移的双视图与独立导出中，抗锯齿边缘可能出现像素差；先独立固定512 Canvas，再直接拼两半，让预览与导出消费同一完成像素。保持源版本而记录旧失败。MediaRecorder 的末帧计数正确也不能推断时间戳准确；必须 ffprobe 帧数与 PTS。十段 actual PNG 经独立 FFmpeg 12FPS 成片已达到精确时间网格，但明确其来源是 PNG 再编码、末尾帧量化，原浏览器24–64ms抖动失败保留。

吃草以真实站立支撑与宽颈曲线作参照；不能为了嘴触地去强迫前腿深折、压低整身。单张实拍只是姿势参照，不能推断所有马通用体型。证据 `examples/horse-neck-path-v3/browser-visual-review.json`，生产 horse24 未变。

### source UV 缓存、批绘与实际呈现计数

源UV裁剪/斜分区与姿态的世界映射应分开，缓存源几何时不要把随姿势变的角度加入key；保留原矩阵映射切分点，不重新warp切分点制造新的形变。只缓存不变数据、不降低原`.2px`自适应精度；新旧100完整RGBA对照及输出不可污染缓存的测试都实际完成。多图源仍按实际mask归属上传，不以整体凸包替换精确pixel runs。

Canvas数千次clip/draw与顶点计算都可能是成本，分阶段量出以后再改。WebGL用同源masked bitmap和完整三角批绘，两Worker预备最多6帧、严格消费连续24FPS索引。FPS必须统计已呈现画面，不能统计发给Worker的请求；暂停、换动作和seek要拒收旧任务，不能抢占新姿态。队列的workerLatency包含等待呈现时间，应与真正主线程submit和交互延迟分开。

本轮 horse24 诊断路径平均24FPS已实测，P95 70～98ms仍有明显抖动；WebGL与Canvas少量AA边像素不同，严格RGBA相等仍失败。GPU坐标精度 .00002622rigpx 与原源点预算通过不接受美术，也不接受目标游戏帧率。具体源SHA、代码快照、193慢速吃草帧/80次关键帧/32PNG当前导出与失败见 `examples/horse-neck-path-performance-v1/review.json`。参考Canvas仍为默认，生产源和绑定未改。


### 2026-10-12 恐龙单骨源与缺图恢复

带膝弯的源图绑定到多段骨链会额外折一次；v13只替换三段腿件，旧头身脚尾保留。动作曾硬编码骨长，已改读实际dimensions；默认328姿势完全一致的验证属于改绑定读取时的v12，不属于后续v13比例修改。32真实关节检视及七动作112帧边界通过不覆盖脚的修长感、厚脚爪、颈尾和跑跳的美术失败。

附加图失败时不能先发布主图缓存；角色全部解码后才发布，错误界面保持切角色和重试可用。文件服务读成功再发200，实际缺源404不应杀死进程。第一次网络失败/第一次恢复失败与真正404恢复成功分别留证，误名截图不能算通过。查看器显示实际消费的多源槽位；连续网格替代的原件不能错误列入。经验已写sprite-art-qa引用，源字节和全QA路径保留。
