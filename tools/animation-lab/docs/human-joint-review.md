## 源比例和配件归属

用户指出原始生图比例正确、组装后反而异常。外星人必须保留自己的大头与细身形；头和躯干使用源图纵横比，分别校准衣领插入点、肩孔中心和鞋底。不得拉长衣服或套用真人头像尺寸填补接缝。

| 位置 | 已落实的规则 | 检查方式 |
| --- | --- | --- |
| 头颈 | 原生头像比例；颈根圆弧藏在衣领后，不能挂出肉盘 | 点头 ±15°、颈 ±20°，中立及极限、正常不透明画面 |
| 肩袖 | 袖子只属于上臂；无袖背心保留真实透明袖孔，肩臂填满孔内 | 肩 -180–45°，高举/后摆；肩核在身体后，衣边在手臂前 |
| 叠层 | 衣领和袖孔边缘必须与身体共享角度及网格绑定 | 同一源地标世界位置重合；弯腰、团身翻滚复测 |
| 肘腕 | 端部圆润、隐藏重叠；三种手型与持物分别校准腕点 | 肘 0–140°、腕 ±25°，近远侧分别检查 |
| 腰髋 | 连续衣摆与裤料蒙皮、骨盆覆盖大腿根，不能出现额外屁股 | 髋 -110–45°、深蹲、弯腰和团身 |
| 膝 | 大腿52、小腿46，根粗向膝收窄；端部圆弧不过度鼓起 | 膝0–145°、屈髋抬腿、快跑回收 |
| 踝鞋 | 鞋/踝在裤脚后，留短踝段；真人鞋宽34、外星靴宽33 | 踝±20°、极限屈膝、跳跃、翻滚；源鞋底对齐地面 |

圆形衔接核由同材质贴图构成并被父子零件遮住，允许内部球形组合；不画机械插槽。隐藏圆帽不应在极限转动后成为额外肉块或第二个臀部。

## 逐关节路径

`/lab → 人 → 日常装/外星探索者 → 零件 → 选中接头 → 单独测试 → 帧01/05/13`，再选局部组合，最后完整角色。默认不透明；“淡化其他件”只用于看遮住的内部，不作为整个人的验收证据。先确认页面实际皮肤和版本，再保存截图，不能靠文件名判断角色身份。

头、颈以及两侧肩肘腕/髋膝踝共14处；每种皮肤14单件＋14组合＋8完整动作＝36条技术路径，两种合计72条。alpha检查每关节65次，并单列手型素材和衣物遮挡方向。它能发现轴点透明、缺素材和反向遮挡，不能判断肤色、衣料褶皱、圆帽凸起或运动自然度。

当前真人局部证据复用绑定未变的 `human-v16-opaque-*-light.png`；外星人复用 `human-alien-v5-opaque-*-light.png`，并有头颈肩4×近景。v17/v6修改针对翻滚脊柱和衣物弯曲，全部16帧另存。复用范围和源码哈希写入各自 `art-review.json`，旧版翻滚失败帧不复用为通过。

## 真实动作参考与项目用例

参考来自真实人体运动教学资料；本轮没有拍摄真人视频或使用动捕，阈值是当前52px大腿的项目标准，不能冒充人体统计常模。

| 参考 | 项目用例与明确拒收项 |
| --- | --- |
| [World Athletics：Schiffer, The Sprints, 2009 pp.10–11](https://worldathletics.org/download/downloadnsa?filename=f411d6b2-f0be-456f-b969-28abad2159ce.pdf&urlslug=the-sprints)；[短跑动作分期](https://worldathletics.org/news/news/neuro-biomechanics-of-maximum-velocity-sprint) | 两侧膝能回收到髋高；后跟回收；同侧腿前抬时臂后摆且肘屈曲；连续支撑世界脚坐标变化＜0.02px |
| [Independent Gymnastics Association 技术教学](https://www.independentgymnastics.com/technique-toolbox/) | 前滚翻先双掌着地、收下巴再翻滚，头不得作为地面支撑；禁止整个人直接绕点打转 |
| [NASA Human Integration Design Handbook](https://www.nasa.gov/human-integration-design-handbook/) | 人体头像比例测量区分头部和颈部，不能把含颈的整块源图高度当作头高；未引入未经核实的标准人口比例 |

翻滚相位：0.24双掌触地、0.40开始旋转、0.84回脚；0.24–0.32掌底与地面误差＜0.01px且无根位移。团身采用保持弧长的脊柱曲线，衣服、颈根、肩点沿同一曲线变形。真实贴图轮廓接地外，额外在0.24–0.95每0.01采样拒收头轮廓离地≤0.5px，避免“接地通过但实际头在地上”。这是二维动画，不是关节动力学仿真。

## 失败与复测记录

外星人旧版躯干被拉长、袖孔空心、颈根肉盘以及衣边不随躯干旋转均直接登记失败。衣边错误的同姿势复测为 `human-alien-v5-collar-underlay-roll-retest-05.png`（仍失败）→ `human-alien-v5-rim-rotation-roll-retest-05.png`（修正）。真人v16及外星人v5旧翻滚有头触地，改为v17/v6的16帧团身证据。误标皮肤和取景异常批次保留为无效证据，不能计入审核通过。

查看 [QA路径总索引](qa-paths.md) 和 `/art-qa`。本轮86项回归通过，导出8动作×16帧×2皮肤，最小透明留边真人25px、外星人42px。技术报告、实际看图观察、用户认可分开记录。仍需目标游戏性能、持物复杂动作组合及其他动物专项复核；微小膝部材质边缘保持美术检查项。
