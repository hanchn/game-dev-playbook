# 十类角色动作设计

这些原型设计说明保留初期结构方案。当前十类角色已使用圆弧真实贴图和多动作，完整覆盖见 [圆弧零件工作流](../rounded-parts-workflow.md)；工作台与导出的 actionDesign 描述当前实际实现。二维动画不代表生物级物理仿真。

| 资产 | 零件结构与代表动作 | 说明 |
| --- | --- | --- |
| 人 | 两腿、双臂、头与躯干；走路与单腿伸展 | [人](human.md) |
| 鸡 | 双足、双翼；短步快走与单腿伸展 | [鸡](chicken.md) |
| 恐龙 | 双腿、短前肢、尾链；走路与平衡 | [恐龙](dinosaur.md) |
| 马 | 四腿、头与躯干；对角小跑 | [马](horse.md) |
| 鳄鱼 | 四腿、低躯干、尾链；低姿态行走 | [鳄鱼](crocodile.md) |
| 百足虫 | 十对腿；逐对延迟的波状步态 | [百足虫](centipede.md) |
| 蜘蛛 | 八腿；单腿收拢伸展与四足分组 | [蜘蛛](spider.md) |
| 蝎子 | 八腿、双螯、尾链；步行与尾摆 | [蝎子](scorpion.md) |
| 蛇 | 十二节身体链；横向身体波 | [蛇](snake.md) |
| 蚯蚓 | 十二节身体链；收缩舒展波 | [蚯蚓](worm.md) |

在工作台选中对应资产，动作设计标签展示可导出的结构化说明。新增动作前，先写参与零件、姿势和限制，添加单件正常/故障样本，再实现局部与完整协调。
