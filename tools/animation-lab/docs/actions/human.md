# 人 · 侧面动作设计 v2

视角：正交侧面、朝右。

固定正交侧面朝右。先远侧肢体，再躯干、颈头，最后近侧肢体。肩、肘、腕、髋、膝、踝轴点仅存在于骨骼数据中；贴图在连接处覆盖重叠，游戏导出不显示轴点。

## 单配件屈伸

周期：1s

参与：选中上臂、前臂、大腿、小腿或其对应肢体链；其余肢体固定

关键姿势：0% 中性姿势 → 25% 正向屈曲 → 50% 中性姿势 → 75% 反向伸展 → 100% 回到起点

时序：单件模式只旋转选中关节，下游零件跟随；局部模式回放整条肢体

关节范围：上臂 ±28°；前臂 8–78°；髋 -15–35°；膝 15–85°；腕 ±18°；踝 ±15°

接地：配件测试脚端悬空，不应用支撑锁地约束

验收：父关节位置固定；骨段长度恒定；下游连接连续；非选中肢体保持静止；循环末首一致

## 侧面行走

周期：1s

参与：body、neck、head、leg-0-upper、leg-0-lower、leg-0-foot、arm-0-upper、arm-0-lower、arm-0-hand、leg-1-upper、leg-1-lower、leg-1-foot、arm-1-upper、arm-1-lower、arm-1-hand

关键姿势：0% 近腿支撑，远腿回摆 → 25% 远脚抬起回摆，近臂后摆 → 50% 两腿交换 → 75% 近脚回摆，远臂后摆 → 100% 回到循环起点

时序：左右腿相差半周期；手臂与同侧腿反向；躯干起伏 1.5 px

关节范围：大腿与小腿长度 49 px；步幅不超过 23 px；回摆抬脚 18 px

接地：支撑脚踝高度 -11 px，鞋底贴地；根运动单独输出以验证世界坐标脚端稳定

验收：左右腿交替；支撑脚不滑动；鞋底不穿地；肩肘腕/髋膝踝连接不脱离；循环连续

## 人工视觉验收

一个可见侧面眼睛，面部朝右

躯干、肢体、鞋统一侧面，不混入正面与俯视

关节没有机械卡点，快慢速检查重叠处裂缝

目标游戏尺寸检查轮廓和动作可读性

## 当前限制

这是二维刚性零件动画，关节纹理变形仍需人工调整。

不自动把技术通过当作美术通过；俯拍、背面尚未制作。
