# 固定整臂控制与真实生成失败探针

`controls.mjs` 生成 1254×1254 的 12 相位肩→肘→腕参考图；不变形任何角色源 PNG，也不是最终美术或运动捕捉。永久蓝色 far/握拳，红色 near/张手，上臂和前臂各225px；两侧肩根固定。相位3/9经过时两臂会接近，源遮挡须再实看。正弦轨迹有7个不同上臂姿势、12个时间相位，不能宣传12个不同胳膊姿势。

数学检查包括骨长、肩根、连续周期和相位相反；冻结远臂、两臂同相、根漂移、腕断链四项故障全部拒收。参考的人体研究只支持摆臂平衡摆腿角动量的原则，具体角度和比例属于拟人奶蛙的风格化控制，并非论文测量或生物自然度认证。

实际 imagegen 首轮 `frame-08-v5.png` 移除了过早前摆的远拳，但肘约425,510、拳约505,665，仍为过强后摆，偏离8号控制肘546,630/腕698,795。一次定点修复 `frame-08-v6.png` 反而使近侧张手变成圆曲指形，远拳没有独立可见轮廓，永久身份失败。这两张均未替换 v7 生产候选。原图和提示/输入输出 SHA 在 generation-inputs 和 receipts 保存；native α≥24 均无触边，脚底分别1204/1205，仍不能推定注册合格。

两个单帧失败探针均在 `/frame-animation` 可选择，名称明确“非动画”；实际浏览器载入和原生屏幕像素已实看：`ui-probe-v5.png`、`ui-probe-v6.png`。没有把两个同相位备选串成新的跑步序列或影片。
