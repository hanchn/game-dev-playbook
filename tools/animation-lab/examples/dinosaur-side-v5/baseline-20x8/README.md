# Dinosaur side v5 — actual PNG evidence

审查状态：**技术导出通过，美术失败，用户未验收**。本目录保留 2026-10-11 本轮恐龙完整动作，未修改源图、主骨架或注册数据。

`idle / walk / run / jump / roar / bite / tail.png` 每张为真正透明 PNG、2048×2048、4×4 格、每格 512×512。七个 `*-frames.json` 记录相位、帧坐标、时长、循环语义、源图与实现哈希，可用于关键帧和序列帧工具真实测试。循环采样 `i/16`；非循环采样 `i/15` 含末帧。对应 `*-animation.json` 保留完整姿势；`frames/` 保留 112 张单帧。

`*-dark-contact.png` 与 `*-light-contact.png` 是带标签和地面线的自测图，不能当作透明游戏图集。已查看全部 14 张 contact sheet；`review/` 是选定实际 PNG 局部三倍放大，两种背景，部分只生成未查看，实际查看范围在 `art-qa-report.json.reviewed` 中逐项标明。

尾巴浅线在正常不透明画面与浅色背景都能看到，原始尾素材没有等距竖线。它是实际导出画面中的缺陷；`strip-skin` 三角形接边抗锯齿是待验证的原因，不能将推测写成已定位根因。尾根是连续但材质/轮廓接合失败，没有宣称透明断开。脚已有爪而非鞋，但足与踝的凸起、回收姿势还需校准。

`technical-report.json` 保存逐动作基线、故障拒收、原始足端/实际足底像素、三档 alpha 留边检查和当前独立 gait 检查。112 帧未截断，最低留边 44 px；支撑脚实际高 alpha 足底离地面线 1–2 px，这是栅格/地面线取样差异，不等于地形碰撞通过。内侧冻结、内侧同相故障在正常标签保留的条件下均被独立检测拒绝。`sheet-png-checks.json` 用另外的 PNG 解码器对所有图集逐格再次检查。

`art-qa-report.json` 分别记录每动作失败、证据、相位和同姿势复测要求。正常/0.25 倍实时播放、独立关节极限、浏览器性能与渲染一致性、真实游戏地形仍未在本目录验收。父任务另有 CUA 证据，不能自动合并为本轮已播放。

源图 `/art/dinosaur-side-parts-v5.png` SHA-256：`2a3ab3e9fbc6463694c10bc42ae6585f8ab0391962accb25b11d360c1bc879ad`。解码原始 PNG 后通过 `@napi-rs/canvas` 调用生产 `drawCanvas` 输出，没有改源像素文件。`asset.json`、`skin.json` 与所有 manifest 保存此次注册快照和实现 hash。图集 hash 不相同就不能复用本报告。
