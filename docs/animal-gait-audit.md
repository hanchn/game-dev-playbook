# 动物近远腿步态审查

审查日期：2026-10-11。状态：**发现与修复建议，未作美术通过判定**。本轮只读检查当前代码、源图和数值轨迹，没有操作浏览器、没有看真实游戏播放，也没有修改主骨架或共享 QA 报告。

适用资产：鸡 v3、恐龙 v4、马 v3、鳄鱼 v3、蜘蛛 v2、蝎子 v3。源图/绑定修改后需重新运行；`audit-gait.mjs` 输出资产、atlas SHA-256 和实现 SHA-256，数字不能跨版本直接复用。

## 已确认的漏检与错误

1. `testAnimal` 的相位检查把第一帧 `legs[].phase` 与产生姿势时使用的模板比较；`testArthropod` 做类似比较。它们能拒绝显式 `fault='phase'`，不能证明实际渲染的远腿经历了另一半周期。正确标签、错误节点或被遮得看不到的腿仍可能漏检。
2. 原有 `frozen` 故障只冻结近侧 `leg 0`。原有横向幅度检查确实会拒绝冻结足端，不应说成完全没有参与检查；缺少的是**内侧冻结、内侧复制近侧轨迹、缺少垂直回收**的专项证据。
3. 当前马 `walk` 的相位偏移 `[0,.5,.25,.75]` 对应实际落脚顺序：近后 → 远前 → 远后 → 近前。它是四拍，但不是本角色普通侧序行走的顺序。独立足端检测得到相对接地时间 `[0,.5,.75,.25]`，目标应为 `[0,.5,.25,.75]`，因此当前偏移需要改为 `[0,.5,.75,.25]`。
4. 所有动物共用 `walk` 支撑占比 `.5`、`run` `.4`，蜘蛛/蝎子共用 `.5`。这把物种差异简化成时间缩放。普通马慢走缺少对侧支撑重叠；鳄鱼低姿态不能直接套马小跑接地关系；快蜘蛛也不能自动按严格四足组模型宣称真实。
5. 马当前 `run` 是对角小跑结构：近后与远前同组，远后与近前同组，并有两次短悬空。只能作为小跑候选。疾驰/跑马需要另外的非对称落脚次序、躯干运动和恢复动作，不能只加快此循环。
6. 目前鸡、恐龙、马、鳄鱼脚端在完整 `walk/run` 中一律保持 `angle=0`。数学接地稳定，但没有明确的脚趾/蹄趾离地、踝部回收、着地缓冲姿势。脚掌素材过长、足段轮廓错位时，端点轨迹正确也会看起来像鞋子或拖板。
7. 蜘蛛/蝎子七段 `solveChain` 未使用已有 `range`，也没有关节角、平面或屈曲方向约束。128 点实际节点采样发现：蜘蛛腿 2 在 walk `t=.359375` 的前两接头折转达 `170.9°/172.2°`；蝎子远腿 3 在 `t=.9140625` 的第二接头达 `175.4°`。相邻骨向量几乎回折，长度/接缝测试依然通过。脚本把 >150° 的短近端回折记录为 `geometryWarnings`，这是筛查阈值而非论文测量的关节上限；需看实际画面后决定缺陷范围，不能仅凭该数值声称物种动作不可能。

## 内侧故障必须被拒绝

脚本在采样输出上注入故障，而不是切换骨架原有故障开关。保留正常的相位/支撑标签，修改实际远侧节点，避免测试和实现共享同一个判断条件。

| 故障 | 具体注入 | 客观拒收条件 |
|---|---|---|
| `freeze-inner` | 每条远腿固定在首帧姿势，随腿根平移；近腿照常 | 任一腿相对腿根前后行程 ≤ 3 px、足端垂直范围 ≤ `max(.8, 总骨长*.015)`、没有完整接地→离地→接地，或锁地漂移 |
| `same-phase-inner` | 把远腿节点换成同对近腿节点，保持远腿根位置及所有正常标签 | 对侧实际轨迹最佳循环延迟不在 `.5±.08`，或同相 RMS 差异 ≤ 1 px |

6 个角色 × 2 个动作 × 2 类故障 = **24 个注入候选全部拒绝**。这验证了拒收屏障的针对性，不代表 6 个角色美术通过。

接地从实际足端高度平台推断，平台容差 `.15 px`；相邻推断接地点的世界横坐标漂移须 < `.15 px/采样间隔`。这里用了展示的 `rootX` 作为世界位移；真正游戏必须改用约束后的实际角色位移。不能拿显示器中“锁地”替代地形、碰撞、上下坡接触。

## 源图角度与遮挡风险

已直接查看蜘蛛/蝎子的 v2 源 atlas。它们有独立圆弧零件，但近远腿使用同一套素材和相同宽度；四条远腿根只比近腿多 2 px 的水平差，整条远腿都排在身体后。七节算得出来并不意味着七节轮廓好读。

渲染器根据 source `pivot→distal` 向量对齐骨轴；代数角度正确只说明**手填轴点向量**对齐，不能证明轴点落在真实关节中心，或者弯曲足爪素材的末端正好落在接地点。比如蝎子的跗端素材是弯曲爪，直线 distal 标记不能代替实际爪尖。近远使用同一明暗素材，也可能让两条经过同一区域的腿难以追踪。

脚本另做 16 帧 source-alpha 遮挡筛查：在本地 1 px 网格采样正常不透明装配，对每条腿计算自己的 alpha 面积和经后绘制部件遮挡后仍可见的面积。它包含裁剪和 head-neck 网格变形，未计连续尾 strip、浏览器抗锯齿、颜色对比和感知识别，**只能定位待看的帧**。

| 待复测入口 | 动作 / 帧 / 相位 | 最少可见比例 | 下一步 |
|---|---|---|---|
| `/lab/spider`，远腿 1 | walk / 05 / `.25` | 6.44% | 完整不透明画面追踪足尖，并与 `.75` 相反姿势对照 |
| `/lab/spider`，远腿 3 | walk / 12 / `.6875` | 5.90% | 检查是否与邻腿重合成一条，及正常游戏尺寸是否仍可追踪 |
| `/lab/scorpion`，远腿 1 | walk / 04 / `.1875` | 11.28% | 检查弯曲足爪实际接地与长段角度 |
| `/lab/scorpion`，远腿 3 | run / 12 / `.6875` | 9.76% | 正常速度、0.25 倍速和对应半周期交换检查 |
| `/lab/crocodile`，远后腿 1 | run / 05 / `.25` | 10.03% | 检查低身躯下远脚是否显得缺失或拖地 |

筛查未发现某条腿整周期完全消失；隐藏局部是正常遮挡，不应为了“八条全露出”制造不真实的错位。若某腿整个周期最大可见比例 < 8%，应阻止自动验收并转人工视觉复核。其他角色仍需要两种背景、实际游戏尺寸、完整循环的画面证明。

## 真实参考与使用边界

- **马**：原始实验描述普通 walk 为四拍侧序、约四分之一周期落脚间隔；trot 为对角两拍并有悬空。可用于判定当前马 walk 的顺序错误以及 run 的步态类型。不同品种、速度和其他走步不能硬套本轮固定参数。[Rhodin 等，2022 原始研究](https://www.mdpi.com/2076-2615/12/21/3053)
- **鸡**：研究实际雏鸡的腿支撑时长、地面反力与行走/跑步差异，并发现年龄相关差异。它支持分开测支撑和摆动；未提供当前成年鸡造型可以直接使用的统一角度模板。本轮没有声称已观看该研究视频。[Muir 等，1996 原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC1158940/)
- **鳄类**：美洲短吻鳄原始实验区分低姿态与高行走，并分析速度变化中的近端/远端运动差异。不能把此证据当作所有鳄鱼的疾驰许可；当前 generic crocodile 还未锁定物种，先明确低行走的动作目标。[Reilly 与 Elias，1998 原始研究摘要](https://pubmed.ncbi.nlm.nih.gov/9716509/)。肩带及躯干也会参与步幅，不能只让两个固定髋点带动腿。[Baier 等，2018 作者机构记录](https://digitalcommons.usf.edu/bin_facpub/454/)
- **蜘蛛**：原始实验测量七个腿段及各足接触序列，慢速可近似交替四足组，所测 `Grammostola mollicoma` 的高速序列未保持同样严格的组模型。当前 generic spider 可选择说明为简化步态，不能标记“所有蜘蛛真实动作”。[Biancardi 等，2011 原始研究](https://journals.biologists.com/jeb/article/214/20/3433/10466/Biomechanics-of-octopedal-locomotion-kinematic-and)
- **蝎子**：`Hadrurus arizonensis` 高速摄影原始研究记录对侧/邻侧腿约半周期交替，且同侧腿回收会受后方支撑状态约束。它支持逐腿接地/回收审查；不等于七条线段用同一条自由 FABRIK 链就能自然。[Bowerman，1975 正常行走原始研究摘要](https://link.springer.com/article/10.1007/BF00614529)
- **恐龙**：没有可观察的真实霸王龙步态视频。本轮仅检查两腿身份、姿势衔接与现存二足类的约束启发，不能称为真实恐龙动作验收。骨段、跗部、脚趾归属要分别标清，源图自带弯曲不能冒充额外关节。

## 修复顺序与复测要求

1. 修马普通 walk 的侧序，并按低速目标增加支撑重叠，重新校准 `rootX`，保留先前失败输出。若只实现 trot，把 UI 和导出动作名改为小跑；若需要疾驰，独立设计 canter/gallop。
2. 在关键帧生成器中把每条腿的近远身份、接地、后蹬、回收、下一次前伸作为必填约束。先看两个相反关键姿势，再补中间帧。生成完整图片和分件动画都需使用同一身份表。
3. 鸡/恐龙追踪双腿；马/鳄鱼追踪近前、远前、近后、远后；蜘蛛/蝎子追踪每条腿的七段和足爪，而不是只看整张图有几条凸出的线。
4. 保留完整不透明装配作为验收画面，半透明只看内部。检查上表风险帧、对应半周期和相邻帧，以及七段近端回折姿势；近远两条腿分别暂停核对，目标速度与 0.25 倍播放均检查。短基节/转节采用受限肩/髋接头，长股节/胫节负责主要屈曲；换成保留关节平面、方向和限位的 IK 后，仍须测每条腿，不能让通用七段 FABRIK 任意卷折。
5. 做真实 source-alpha 足爪/蹄底接触检查，而非只查骨端。toe-off、脚端回收角度、膝/踝弯曲方向及远腿轮廓自然度由画面复测确认。
6. 新报告记版本、源图/hash、动作、实际帧、入口、倍率、背景、遮挡开关、观察结果、失败与同姿势复测路径。技术通过、视觉通过、用户认可分开。

### 可复跑命令

```sh
node tools/animation-lab/scripts/audit-gait.mjs --no-pixels
node tools/animation-lab/scripts/audit-gait.mjs horse --strict
node tools/animation-lab/scripts/audit-gait.mjs > /tmp/animal-gait-audit.json
```

`--strict` 在独立基线技术失败或故障漏检时退出 1；默认输出审查 JSON，不在磁盘上覆盖任何旧 QA。父任务可把输出保留到带版本的 `examples` 目录，再将浏览器实际画面和视觉结论追加到对应复测报告。
