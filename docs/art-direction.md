# 可复用的游戏美术方向

美术方向的验收对象是实际游戏画面，而不只是单张概念图。清晰的主体、可信的结构与统一的尺度，比堆叠细节更重要。

## 先锁定视觉样本

建立一页 style bible，记录：

- 目标玩家、游戏情绪和镜头距离。
- 主体比例、轮廓、材质、边缘处理、光照方向与阴影软硬。
- 主色、背景色、奖励色、危险色及文字颜色；颜色同时承担明确的信息职责。
- UI 的边框厚度、按钮体积、图标形态、字体与间距。
- 禁止项，例如无依据的幼态比例、杂乱装饰、廉价塑料质感或互相冲突的线条图标。

成熟卡通可以使用夸张表情和明亮色彩，但保持骨骼、机械结构与空间关系可信。不要用“更可爱”代替具体的脸型、比例、材质要求。奖励和危险不能只依赖颜色，还要有轮廓、图标或文字辅助。

选择一张主视觉样本和一个实际尺寸的游戏截图作为基准。后续资产对照同一基准验收；修改基准时记录版本，避免不同批次各自形成风格。

## 生产顺序与放行条件

1. **主视觉样本**：确认角色、载具、环境与 UI 可在同一画面中成立。
2. **四种代表样本**：普通主体、长尾主体、宽翼或宽体主体、柔性或特殊动作主体；在真实显示大小播放。
3. **UI 框架**：确定按钮、HUD、卡片与弹窗的空槽位置和响应式约束。
4. **场景**：制作无角色背景及独立前、中、后景装饰。
5. **角色与载具**：锁定几何尺度、方向、身体标志与分层关系。
6. **动画**：先验证循环与动作切换，再扩充动作和物种。
7. **状态连接**：将加载、玩法、图鉴、奖励、失败和返回路径连接成完整流程。
8. **音效集成**：按动作与结果配置反馈，检查多次触发、静音和音量。

每一步的验收失败都应先修代表资产。不要在比例、裁切或动画自然度尚未通过时扩大批量。

## 配色与布局

先用大面积环境色建立氛围，再用有限的暖色或高亮色突出操作与奖励。HUD 应能读清且不遮挡关键目标。复杂边框内部保留安静区域，标题、数值与说明分层排列，避免所有文字都同样大、同样亮。

装饰的密度应服务场景：近景有细节，远景有适度衰减；类型不能被距离硬性绑定。镜头拉远时优先减小主体、降低对比，而非过度模糊到失去辨识度。

## 审美验收

在手机、平板和宽屏上观察：主体是否完整、UI 是否统一、文字是否落在设计槽内、重要图标是否易识别、动画是否仍自然。静态截图只负责布局证据，连续播放负责动作证据；二者不能互相替代。
