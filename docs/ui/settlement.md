# 结算与反馈面板：状态、动画、下一步形成闭环

结算不只是装饰框。它说明刚才发生了什么，展示一致的角色反馈，并提供明确的下一步。成功、失败、解锁、受击与投放应共享视觉语言，但不同状态不能混用行为。

| 状态 | 反馈内容 | 动画 | 用户下一步 |
|---|---|---|---|
| 成功结算 | 本局收益/成果 | 庆祝或展示收获，一次播放 | 再来一局、首页 |
| 失败结算 | 本局结果 | 沮丧，一次播放 | 重试、首页 |
| 解锁 | 新获得对象和信息 | 翻卡，确认后飞向图鉴 | 收入图鉴 |
| 受击 | 损伤与代价 | 短暂晃动/表情 | 返回当前操作 |
| 投放 | 交付结果 | 放下或欢呼 | 继续游玩 |

受击和投放通常是局内反馈，不必都变成阻塞弹窗。解锁确认应关闭对应面板并完成收录动作。结算的“再来一局”必须开始新局，“首页”必须回入口，不能仅换文字而仍绑定旧操作。

## 壳、标题与角色插槽

面板先绘制空白外壳，标题字图、角色动画、数值、按钮标签独立。成功与失败标题采用同一字图风格与相近视觉宽度，内容简短。保留一个明确角色区域，空间足够容纳最高手势、帽子、尾巴、船或飞碟。

用稳定头宽、身体或髋部锚点校准跨动作尺度；不要把每一帧按可见包围盒缩放到同一盒子。这样会让伸手时人物变小、收手时变大。载具的比例与宽度应固定；若人物与载具一体图，不能叠加第二艘船“补底”。如果源图已经变形，需要修复素材，而非只让数字层盖住问题。

动画插槽和价格栏不能重叠。需要容纳角色时先调整槽位布局，不能通过非等比压扁载具。角色可靠近指定底边，但锚点必须来自画布和稳定尺度，而非逐帧贴可见底边。

## 播放与滚动

结算动作默认播放一次，结束停在完整姿势。若支持点击角色重播，点击只重启动作，不重复结算收益、不触发新一局，也不与当前播放叠加。背后场景暂停角色、计时和逻辑，避免模糊背景里仍有一个人物重复表演。

能在屏内完成的结算不应滚动。长列表确实需要滚动时，将标题固定在滚动容器之外；内容区可滚动，底部主要操作始终可达。自定义滚动条需要真实绑定滚动位置与可拖动区域，不能只是画一条装饰线。尊重系统滚动的无障碍需求，不因视觉偏好阻断输入。

## 固定出图提示

> 绘制[主题]结算面板空壳，固定比例[宽:高]，光向、金属/木纹与按钮一致。预留标题、完整角色动作、成果数字和两个操作槽，不绘制角色、数字或文字。外框与投影完整透明留边。角色动作另出固定画布，保持人物头宽、载具底盘和镜头一致，最高动作不裁切。

## 手机和平板验收

同时看成功和失败的全部帧及动作切换；检查头部、载具、投影完整，没有尺度跳动和双载具。窄屏、横屏和safe area下标题、结果、按钮都可见。点击头像连续重播不能增加收益。确认结算前后保存数据正确、返回首页和重试能完整闭环。覆盖面板期间观察背景，验证真正暂停而不只是模糊遮挡。
