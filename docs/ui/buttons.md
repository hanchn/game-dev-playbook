# 按钮与虚拟键：图案、文字、点击区分开

精细的游戏按钮应作为完整图案绘制。文字、图标、按下与禁用状态由运行时叠加，方便调整语言、状态和触控大小。按钮图案不承担整个布局容器的职责。

## 固定结构

| 层 | 内容 | 保持什么不变 |
|---|---|---|
| shell | 金属、木头或主题装饰框 | 比例、边角、完整透明边 |
| icon | 功能图标 | 在预留槽内等比 |
| label | 可变按钮文字 | 安全区、对齐、清晰度 |
| feedback | 按下、禁用、进度 | 不改变按钮布局大小 |
| hit area | 指针/触屏输入 | 大于或等于可见图案 |

装饰边与投影都要包含在透明安全边内。看到直线切口时，先检查源图、裁图视口和容器overflow，不要用额外白色边框遮掩接缝。

长按钮不能随容器任意拉宽。固定整体比例，或提供多个比例版本。九切片适用于中间可重复或平滑延展、边角相互独立的壳；一条贯穿全边的绳索、浮雕或弧形高光通常不能随意切开。使用九切片前在最短和最长尺寸验证边角、边纹与中部连接。

## 文字与状态

深色字配浅色槽，浅色字配深色槽。高光不能穿过关键笔画。标题字图可以表达主题，但按钮标签优先独立且易读；若标签也用图，需保留清晰的辅助文本。不要把一部分按钮做成精细立体图，另一部分改成无关的默认扁平样式。

按下反馈可以轻微亮度变化或局部缩放，不能触发布局回流。禁用状态要可辨识且不被误认为未加载图片。键盘焦点应可见，触屏热区可以扩大而不扩大图案。

## 虚拟键

左方向盘以固定中心记录指针偏移，按半径归一化并限制向量长度。摇杆视觉移动与控制向量分开；释放或取消指针时回中且清空输入。右动作键区分按下、持续、松开和取消，不能将长按误触变成多次独立点击。

半透明只作用于视觉层，不降低命中范围。功能说明放在足够清晰的位置，避免被拇指覆盖。圆形图标按真实宽高比展示，不能挤成椭圆。横竖屏的底部safe area均需留出。

## 固定出图提示

> 制作[功能类型]的[主题]按钮空壳，画布[宽×高]，完整边角和投影，四周透明留边[数值]。文字槽位保持空白，图标单独输出。材质、光向、描边与现有UI一致。不要文字、白色外圈或裁切线；提供原始尺寸与内容槽位。

```json
{
  "aspect": 4.6,
  "safeMargin": 0.05,
  "label": {"x": 0.18, "y": 0.25, "w": 0.64, "h": 0.50},
  "icon": {"x": 0.08, "y": 0.25, "w": 0.10, "h": 0.50},
  "hitPaddingPx": 8,
  "scaleMode": "contain"
}
```

## 验收

在手机和平板上检查完整轮廓、文字安全区、触屏热区与横竖屏安全边。测试按下后移出按钮、浏览器丢失焦点、多指输入和禁用状态。最窄屏下不拉伸边框，最大尺寸下不暴露裁图线。视觉与点击区分别检查，不能只凭截图认定交互可用。
