# 序列帧动画的生产与验收

序列帧质量来自源动作连续、尺度一致和导入正确。平移静态图、压低帧率或逐帧缩放，不能替代真正的动作修正。

## 可复用的生产顺序

先定义动作与相位，再验证关键姿势，补完整循环，统一尺度打包，接入游戏与图鉴，最后按角色逐个验收。行走动作先证明近远侧肢体交替；具体方法与可复制验收记录见 [行走与逃跑序列帧](sprite-gait.md)。

“帧图”“动画播放帧率”和“游戏渲染帧率”分开排查：源姿势错误重做帧图，时序错误修播放，运行卡顿先测性能。三者不能互相替代。

## 固定画布与身体尺度

同一个动作采用固定帧画布，主体周围预留足够透明空间。尾巴、翅膀、触须、举手和道具必须在动作最大范围下仍完整。帧数由动作频率和用途决定：六帧可以用于短循环，但不适合所有动作。

角色的头、躯干与载具采用稳定标志测量，而不是仅比较全身包围盒。摆动的手、尾巴和衣服会改变包围盒，不能拿它们决定每帧缩放。

一个动作内尺度固定；不同动作之间按照可信的头部或身体标志统一比例。站起时高度应自然增加，不能为了塞进同一个矩形而缩小人物。多套角色动作优先复用同一 rig 或结构参考。

## 锚点和偏移

记录真实运动方向、身体锚点与载具连接点。头部测量应避开举手等干扰区域，并通过人工确认；自动最长轮廓只是候选估计。

帧元数据中存固定矩形与平移偏移。偏移修正主体在画布中的位置，不改变比例。在 DOM 展示时，裁切层只负责截取当前格，外层再施加偏移。不要修改背景取样位置来完成偏移，否则会露出邻帧。

引擎图集也需区分源矩形、逻辑画布和锚点。转换坐标时检查朝向镜像是否同时影响锚点；长尾主体不能因翻转后锚点错误而尾部先行。

## 角色与车辆

车辆几何在所有动作中固定，人物可在驾驶舱中独立表演。合成时只保留一层车体，避免用第二辆车遮盖变形，产生双车或压扁的船体。

若载具需要倾斜，可使用固定几何的整体旋转或可信的倾斜帧。左右倾斜和回正的首尾状态必须衔接。人物、座舱连接点与车体比例一起检查，不能只保证脸大小相同。

## 循环与动作切换

检查每一对相邻帧以及最后一帧到第一帧。循环动作需要位置、轮廓与节奏闭合；庆祝、伸懒腰等一次性动作应有明确结束状态。

先慢速逐帧观察，再按目标速度播放。低帧率可能放大停顿，高帧率可能掩盖闪变；两种观察都需要。方向变化应平滑，不能靠每帧随机上下偏移制造游动。

不同用途分别验收：世界中的正常尺寸、图鉴的近距离展示、加载中的小尺寸和结算中的大尺寸。一次通过不能推断其他尺寸无裁切。

## 自动检查与人工放行

自动检查至少包含路径、图像尺寸、帧矩形合法性、透明安全边距、空帧、包围盒差异与首尾差异。差异数值是排查线索，不是自然度结论。

人工检查：

- 头部和身体比例有无跳变。
- 车辆几何及角色连接点是否稳定。
- 手脚、尾翼、触须和道具是否完整。
- 真实朝向是否与运动方向一致。
- 相邻帧和循环是否有抽搐、停顿或突然缩放。
- 裁切、透明光晕和投影是否在深浅背景上正常。

失败时记录具体帧号、显示尺寸和复现状态。临时跳过问题帧需要明确标记，不能称作完整修复；源动作有结构错误时应重做源素材。

## 小批量到批量

按动作结构与风险选择代表样本，例如四足、双足、长尾或宽翼，实际播放通过后再扩充资产。样本数量由覆盖范围决定，不能固定四个就认为所有角色都有代表。保留原图、失败版本、导入配置和验收记录。每一批新增资产都必须经过同一套播放链路，而不是只检查文件数量。

分别记录生成候选、技术边界通过、逐帧视觉通过、接入待验收、真实游戏通过和用户认可。代表样本认可不能替整批角色签收，构建和逻辑测试不能提升视觉验收状态。

行走、逃跑、停步抽搐与滑步的具体排查见 [步态专项经验](sprite-gait.md)。

## 可运行的验收工具

[序列帧验收工具](../tools/sprite-animation-review/README.md) 是独立的 Phaser 预览应用，可载入本机图集和角色配置，支持角色选择、慢放、暂停、前后逐帧、换向、深浅背景、完整帧网格与原比例导出。另提供只读 PNG 矩形、空帧、安全边距和播放序列检查。工具只含技术示例，私有游戏素材不随知识仓库发布。

## 纯2D分层试玩批次（2026-10-15）

角色生成与运行时集成可并行，但必须用稳定的部件契约衔接：core、upperArm、forearm、thigh、shin、portrait 六个独立矩形，附真实 PNG 尺寸、alpha 可见边界、局部关节 pivot 与世界肢体长度。先接入两名有独立身份的角色实际对打，再扩充整队；立绘不等于战斗图集，生成图集也不等于动作验收。原始 PNG 保存在私有游戏仓库，公共知识库只保留方法。

生成器可能忽略六格要求，或让部件越过名义格边界；检查实际组件范围，不能机械切512格。pivot 可以在裁切矩形外，属于合法原点，不应钳制到0..1。分层躯干的肩膀不能默认都放在 x±7：按图中两侧插槽实际测量，否则会出现手臂从胸口长出、原插槽外露。腿层在躯干后、上臂覆盖接缝；同一缩放系数未必适用于长度与厚度。

这类 rig 是重建动画辅助工具，不是恢复街霸原始骨骼，也不能替代最终逐帧姿势质量。测试须分层：核心逻辑（输入、跳跃落地、命中顿帧、击倒、回合）、rig 几何（脚底、朝向、有限关节坐标）、Phaser 实际画面（接缝、比例、遮挡、技能）。首批实现33项测试及构建通过，并在实际浏览器验证双角色伤害、回合切换、大招输入、暂停恢复；已发现的接缝和姿势缺陷继续记录，不能因测试通过宣称美术完成。

CSS grid 内 Phaser 自动 margin 会把窄屏画布推出视口；画布须显式保持2:1比例并清除旧margin。前端资源热更新会重置运行中的对局，制作期测试须区分真正战斗错误与热更新。对应私有游戏首批提交 2bcde15，后续测量修正独立提交。
