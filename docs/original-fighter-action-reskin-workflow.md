# 原格斗动作逐帧换图生产标准

2026-10-16 已验证方法，入口：[`original-fighter-action-reskin`](../skills/original-fighter-action-reskin/SKILL.md)。本经验包只共享流程、通用拆帧脚本和失败根因，私有角色图与ROM保留在私有项目。

- 从原机实际动作图清点独立姿势，跨动作复用同源图片；保持各定位元素的持帧、偏移、pivot和原始刷新率。不强制四图/十二帧。
- 固定角色身份/样式参考，加原角色真实姿势参考；原作全身姿势作为第一参考，身份定稿第二；不要把含其他攻击动作的透明条带当作纯格式参考，模型曾抄错招式。横向单排便于提取，实际alpha仍须逐图合成检查。
- 每张处理并检查后即接入原UI与正式引擎；数据revision更新让已有页面加载新图。缺帧显式标记，不代播其他动作。
- 逐帧依据原角色水平基准、对应地标及实体/镜头位移注册，不把起跳、下蹲强制贴到同一地面，也不逐帧自适应缩放。
- 矩形边界不足以隔离邻帧：侧踢脚尖与邻帧肩部在X投影重叠，可引起本帧被截且混入邻帧。用真实alpha像素归属提取；保留本体原RGBA，通过同姿势引擎截图和原像素身份复测。通用脚本对相触角色或独立配件会停止，不能猜组件数。
- 技术图数/时序通过、美术姿势精度、用户接受、原游戏碰撞与状态机分别验收。已有13个观察窗口映射不等于源角色所有招式全部恢复。

实测范围：60张对应新图，13段原机观察窗口，共387个帧序元素；实际Phaser逐元素检查无缺图、对应底边误差低于1e-6；1/4播放4秒推进59个原机tick。原机源频率约59.185606Hz，实际浏览器渲染fps独立测量，不能据此声称60fps。原角色其他招式、碰撞、取消及命中停顿仍需独立取证。

脚本依赖 Python、Pillow、NumPy。脚本和精确限制见Skill；不要将本机私有路径写进通用脚本或公开包。

后续复核纠正：零alpha背景中的RGB在部分预览里看似光晕；真实白底合成干净，最大alpha254也不代表背景失败。曾据预览反复生成是错误诊断，已在Skill记录并改为深浅底真实合成验证。多行能否正确透明须逐图判断。

舰队批次按角色隔离并行生成，集成者统一索引和引擎验收；用户指出源下肢固定却生成晃动、源腿偏移却目标只做上半身，现强制逐髋膝踝足及支撑区对比，数值底边对齐不能替代美术结论。
