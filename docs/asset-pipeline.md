# 资源生产与导入流程

## 街霸移植：原生单帧规格（2026-10-15）

原始帧画布大小、alpha可见边界、有效轴心、AIR偏移、图集存储矩形与显示比例分别保存。图集页可以统一大小，每帧真实宽高、偏移、轴心和时长不能因此改变。禁止逐帧按可见外接框缩放；alpha最低点不一定是支撑脚，尤其在跳跃、倒地、尾巴或投影存在时。左右翻转须同时变换轴心和碰撞框，不对称角色需要核查独立朝向。

复现脚本：`tools/attack-library/scripts/audit-sf-frame-geometry.py`；报告：`tools/attack-library/data/research/sf-frame-geometry.json`。本轮核查5位街霸MUGEN改编角色495帧：肯宽50–116、高46–122；古烈宽59–148、高37–131；春丽宽50–133、高30–128；罗兰多宽59–198、高41–139；伊格尔宽53–153、高36–133。这些数字只适用于上述改编包，不是卡普空原版的统一规格。

验收顺序：原包/哈希 → 帧尺寸/透明度 → 轴心/朝向 → 帧序/时长 → 接触点/判定 → 引擎正常速度与慢放 → 美术验收。整页AI生成可能出现格网漂移、重复姿势、越界与半透明底色；格数不能作为有效动画帧数，未通过的候选保留失败记录并隔离运行时。

生产链应保留原始资源、导入元数据和验收结果，能够重跑导入而不覆盖人工确认的信息。源图完整不代表运行时完整，HTTP 成功也不代表资源已解码和绘制。

## 目录与命名

建议采用清晰的职责目录：

- `art/originals/`：原始产物与候选版本，保留失败候选。
- `art/qa/`：边界、连续性、尺寸与实际播放验收记录。
- `public/assets/characters/`：角色图集。
- `public/assets/scenery/`：背景、前景与装饰。
- `public/assets/ui/`：按钮、图标、标题、数字与框架。
- `data/asset-manifest.json`：运行时路径、尺度、帧信息和来源。

名称采用 `subject-action-version.ext`，例如 `pilot-idle-v2.png`。版本号与动作名独立；不要将“最终版”作为可追踪的版本标识。已发布资产替换前保留上一版。

## Manifest 的最低字段

每个资源应记录 `id`、`path`、`kind`、`version`、`source`、`width`、`height`、`status`。动画另记录：

- `frames`：每帧的 `x`、`y`、`width`、`height`、`offsetX`、`offsetY`。
- `direction`、`bodyWidth`、`anchors`：真实朝向与统一尺度依据。
- `fps`、`loop`、`playOrder`：动画用途与顺序。
- `stride`：采用路程驱动行走时的单周期步幅及显示尺度依据。
- `safeMargin`、`qa`：自动检查结果和人工播放结论。

`source` 保存来源标识及可用元数据；公开经验文档无需包含项目私有资源。动画 `status` 与证据按 [分级验收](sprite-gait.md#6-用分级验收代替已经做好) 记录，另保留拒收或弃用原因。接入资源、通过技术检查和用户认可分别记录。

## PNG、SVG 与图集

PNG 检查尺寸、色彩格式、透明通道和真实透明边界。带透明通道的图片仍可能有低透明度背景光晕，实际叠在浅色和深色背景上各观察一次。

SVG 检查 `viewBox`、纵横比、裁切范围和依赖路径。嵌入位图的封装不增加源图清晰度；其作用是保持比例与裁切边界。SVG 作为图片加载时，外链图片依赖可能被浏览器限制，应在目标环境验证，不能仅根据本地预览推断。

图集检查每帧是否越出源图、是否露出邻帧、主体是否完整、透明留边是否足够。固定画布与运行时显示大小分开记录，禁止逐帧按可见包围盒改变尺度。

## 导入与加载

加载完成需覆盖图片请求、解码、图集注册、UI 数字与图标，以及首次纹理上传或绘制。游戏切入前，让即将显示的静态场景和对象完成初始化；有意从边缘进入的实体属于玩法生成，不能与未加载完成混淆。

UI 的加载位置和样式由产品流程决定。例如开始按钮可原位变成加载轨道，不必追加第二个进度条或弹窗。进度数值应对应实际阶段，不用计时器假装网络完成。

## 验收关卡

先验证一个样本的完整链路，再按动作结构和轮廓风险选择代表样本，最后批量导入；样本数量不能替代覆盖范围。自动检查应阻止缺失路径、空帧和边界溢出；人工验收负责自然度、方向、尺寸一致性和场景适配。

相邻帧有像素差异只能证明不是完全相同的图片，不能证明动画连续。记录首尾循环、慢速回放和正常速度播放的观察，必要时标记源图需要重做。

每次修改后检查重跑脚本是否覆盖人工锚点或特殊播放顺序。对这类信息使用明确的配置覆盖层，而非让脚本静默重置。

### CPS2原版透明帧的核验

SSF2T的原版对象帧可由已核验ROM、MAME 0.289解码图形区、实际锁存渲染对象与调色板只读重建。不要用背景色抠图：硬件透明pen15与黑色描边不同。逐帧保持图块组合画布、alpha边、屏幕位置、RAM投影原点及时间；图块组合范围不是Capcom原始绘图工程的画布，投影原点也不等于已恢复美术轴心。

当前研究库保留隆62个不同RGBA姿势与肯4个待机姿势，1287条接受观察全部与原版截图的不透明像素100%一致，95条观察被拒收。隆的图块组合画布宽64–160、高64–128，不能为了图集整齐统一当成96×96再丢失偏移。详细方法、失败样本与复现见 [Phaser Epic案例第10节](cases/street-fighter-phaser-epics.md#10-透明原版角色帧与真实图块画布e03b)。
