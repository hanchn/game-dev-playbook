# 蚓力狂奔：消息框、断体扣命与无限分层地图经验（2026-10-13）

## 实战来源与状态
来源：hanchn/worm-run。本文整理产品确认、实现方法、失败方案与验证范围。
已有参考：docs/cases/worm-run-platform-adventure.md。本文补充死亡过场和消息框，不覆盖旧案例。
游戏构建通过不代表素材审美、所有设备和无限关卡公平性已经通过。保留原图和失败截图。

## UI 必须使用真实设计素材
自然绘本卡通场景，金黄立体中文标题「蚓力狂奔」，英文 Worm Run；木质叶片四向盘、独立动作按钮。
菜单、暂停、结算、确认、死亡扣命和短消息需要统一视觉系统。不能只替换主菜单，却留下纯色细线消息框。
动态文字和数字使用独立DOM；木框、纸面、叶片为真实透明PNG，不把整张概念图当可交互UI。

## 横幅接缝与超长文字
失败一：把近方形 menu-panel.png 用18%九宫格压成短横幅，木纹和侧框在两边接断。
失败二：只换完整背景图或设置固定宽高，超长消息无法适配。
失败三：改为三段横向切片后只给固定上下padding，文字仍超过纸面，压在木框上。

最终方法：
1. 制作独立横幅PNG，完整左右端帽、连续上/下木框、安静纸面、透明外围；原图保持不改。
2. 横向三段切片：源图左1/4、中央1/2、右1/4。所有段使用同一个纵向缩放，不再分割上下边框。
3. 左右端帽目标宽度 = 源端帽宽 / 源图高 × 框体高度；窄框限制为框宽27%，避免中央空间为负。
4. 中段只在水平方向伸展，两段边界使用同一计算结果，不独立取整。Canvas按devicePixelRatio最多2倍绘制。
5. 文字限定最大宽度，允许换行与连续长词断行。用ResizeObserver读取实际文字高度。
6. 本素材纸面安全高度约为全高32%；框高 = max(90px, ceil(文字高度 / 0.32))。文字居中，不用固定高度猜测行数。32%是这一张素材的注册参数，不是所有UI的常量。
7. 检查短消息、长消息、窄屏多行、长词、缩放和不同DPR。文字边界必须落在纸面内，而非仅在外框内。

实现：worm-run/src/message-frame.js；样例：worm-run/qa/message-frame.html；证据：worm-run/docs/qa/message-frame-long.png。
生成工具：内置imagegen。新素材为message-banner.png；最初错误方案和生成原图不删除。
本次实际浏览器验证短消息与窄屏长消息完整包裹，生产构建通过。不是所有语言和任意无限长度信息的通用排版验收。

## 死亡必须展示身体变化和命数扣减
玩法：三条命；计时耐久随时间减少，碰撞扣耐久、眩晕和保护冷却。耐久耗尽断体；现有天敌咬断也触发断体。
身体分成长短两段，长段继续控制，短段脱离；最后一条命耗尽后结算。
原问题：顶部爱心变化和短toast不足以表达死亡，断体效果过快且没有明确扣命展示。

过场节奏：
- 0–0.25秒：显示原长度；
- 随后分成两段，短段向后下方脱离，长段保留；
- 0.95秒：命数由3→2、2→1或1→0，顶部HUD同步，短音效反馈；
- 2.4秒：有命恢复原地图与缩短身体，无命进入结算。

使用当前蚯蚓连续蒙皮而非用线段代替身体；保留原身体、原长度、长短段长度与命数前后值作为split事件数据。
过场暂停模型时间、耐久、卫兵与输入，但允许断体视觉特效继续推进。切后台不跳过整个过场。最后一命同样先播完动画。
UI复用绘制的木质纸面板与生命图标。输入需清空，避免恢复后继承按住状态。
测试：事件数据独立快照；长段+短段长度=原长；过场不推进耐久/敌人；最后split在result之前。实际窄屏截图和控制台检查单独记录。
37项项目逻辑测试与构建通过，不用测试数替代美术验收。

## 连续身体、四种动物与动作
蚯蚓：可伸缩身体骨链+连续蒙皮；波浪钻行、抬头、跳跃、落枝为姿态；盘卷/滚动/展开为技能形态，未完成技能不能标记已实现。
蛇：连续骨链，盘伏/游动/警戒/追游/蓄势/咬击/恢复。
百足虫：身体链与近远多腿波状步态，爬行/探查/追击/扑咬/恢复。
公鸡：分件骨骼，站立/行走/啄食/警戒/奔跑/啄击/恢复，不能把母鸡素材当公鸡。
行为状态和动画状态分开，共用动作接口但不强行共用同一骨架。原资产预设、技术通过、美术通过、游戏接入分别记录。
连续身体回头、出土不能把每节强投影到同一个地面点；单节间距和整体头尾跨度需实际逐帧检查，源UV跨度为零必须防止非法仿射。

## 无限地图与地下卫兵
无限不是一张大图片，而是按世界种子、块坐标、版本生成附近块并回收远块。
先保留可通过路线和完整身体净空，再放石头、钻石和敌人。地下图需要分叉、汇合、奖励支路和出土口，边界连接口一致。
主路线不能被卫兵永久堵死；通行窗口按完整身体通过所需时间计算。百足虫巡逻和蛇路口伏击提供观察/转身/攻击恢复窗口，玩家可等待、跟随或绕路。
静态四邻接连通不能证明跳跃可达或动态敌人公平。跳跃验证要用实际速度、重力、初速度、完整身体、落脚平台和跨块区域。
树枝必须接在树干上；树间跳空后落到下方枝或地面，落地不是自动失败，但会进入鸡的危险区。
所有左右路线、分叉和天气随机应可复现；装饰随机与玩法随机分开。同屏角色、缓存、效果和稀疏状态有预算。

## 前中后景与玩法区域不能混淆
地下/地面/空中是玩法区域；前中后景是视觉层次。
天空、太阳、远林农舍缓慢滚动；中景承载地形/角色/奖励；前景叶片稍快但不挡敌人、落点或蚯蚓头；HUD固定屏幕。
装饰树不自动有碰撞；可站树枝必须显式注册平台。整张绘本概念图需拆透明树木、草丛、土层、石头、远景和UI。
