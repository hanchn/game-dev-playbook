# 胶囊森林：绘制 UI、飞行反馈与帧动画修复

整理日期：2026-10-10。本文保存可复用方法；私有项目的原图、生成提示词、截图与角色资料留在源项目。状态按具体观察记录，不因构建成功或素材生成数量提升验收等级。

## 1. 先固定层级，再增加动效

首页的背景、静态围观角色、悬浮载具、驾驶员、悬挂物、灯光和界面分别管理。静态背景角色应融入同一光向、尺度和遮挡，不能把各自带树木与草丛的矩形图片拼贴成四个小场景。用户要求背景动物静止时，不给它们额外呼吸、位移或奔跑循环。

固定车体和玻璃罩；驾驶员另用完整姿势帧，前舱沿遮挡人物下半身。重复叠加玻璃罩反光会产生双边与错位，不能通过缩放整车解决。悬挂物使用共同根节点：连接绳在车体后、网袋与内容物作为同一完整轮廓摆动，旋转中心放在吊点。已收口的网袋不能使用一张展开撒网覆盖直立角色。

喷焰位置绑定引擎局部坐标，随船体倾角旋转。待机保持短而弱，移动时按实际速度增长长度与亮度；关闭动力时停止喷焰。光照、偶发落叶和灯光呼吸不应触发背景角色的动作。

## 2. 绘制外壳和可交互内容分离

先画空白 UI 外壳，代码提供文字、数字、点击区域与状态。不要在已经包含按钮槽位的外壳里再塞一张完整按钮，造成按钮套按钮。卡片标题、主要操作和左右导航须对齐到素材实际窗口，不能仅按图片整个矩形居中。

地图选中同时改变整卡亮度、浮起高度和选中标记；未解锁统一置灰并阻止进入。地图列表和解锁状态来自数据，不能按 DOM 位置推断身份。手机尺寸实测后再放行：小描边可能在大图清晰、缩小后完全看不见。

切片伸缩看板时，将圆形仪表、可伸长中段、右端盖分开。只伸缩中段，圆形仪表保持等比。短消息展开、停留、收回；重复消息更新同一实例并取消旧计时器，不堆叠常驻提示。

## 3. SVG 裁取 PNG 的两个不同风险

本例 SVG 仅作为 PNG 视窗，不用于重新描绘 UI。

1. 源矩形本身包含下一行素材：缩小视窗高度或修正真实源矩形，先确认没有截断本主体。
2. 视窗比例与目标盒不一致：默认保留比例可能产生空白并暴露邻格；明确裁取视窗、设置 overflow，并区分可以横向伸缩的面板中段与必须等比的角色/圆形仪表。

只加 `overflow:hidden` 无法修复已经选进源矩形的邻格。只改宽度也无法修复旧样式中的固定高度或 max-height。检查计算后的宽高、源矩形和实际缩放截图，避免 CSS 多版本覆盖让旧限制继续生效。

## 4. 飞行边界、耐久与坠毁是三个状态

若耐久就是剩余时间，显示和模型只维护同一个量：自然计时与受击扣时都影响同一剩余值，圆形倒计时读取该值。不能另有一套 HP 与计时分别归零。

上方和左右边界的碰撞应按实际可视区域及船体尺寸计算。缩放后的摄像机 scroll 不一定就是可视左上角，需要核对中心缩放后的坐标换算。按住撞墙方向时，给向内反弹速度一个短保护时间，否则下一帧的输入立刻抵消反弹，视觉上只像贴墙限位。默认无输入时倾角平滑回零。

下方操作区若定义为坠毁区，进入后不再回弹。切入坠毁状态时禁用捕捉、喂食、出售和打开覆盖界面，取消未完成捕捉及攻击物，熄灭喷焰。演出依次包括：失去升力的停顿/抖动、加速下落、撞击扬尘和震动、替换损坏船体、驾驶员撤离、结算。只把原船淡出再开弹窗不能表达坠毁。

原船替换为损坏版本一次，不能叠两艘船；损坏图的镜头、底盘和尺度需一致。落地阶段要检查是否被底部操作区挡住，必要时淡出控制区。演出过程中仍允许声音切换，但不得通过打开图鉴暂停在半空。

## 5. 帧动画修复：源姿势和播放顺序都要查

先读 [步态方法](../sprite-gait.md)，逐帧追踪髋→膝→脚与肩→肘→手腕。两张图外观不同，但近侧腿仍在同一位置，只能算重复姿势；近侧拳头移动也不能证明整个摆臂正确。近远腿身份必须由身体连接、服装特征与遮挡共同判断。

两次相同错误后停止该生成方式，记录失败原因，改变动作参考或造型参考分工。先验证相反关键姿势，再补承重和回收。不能把一张逃跑姿势平移出屏冒充逃跑帧动画，也不能用整只角色镜像代替换腿。

正确源帧还需正确播放相位。四帧的格子/生成顺序不是默认动作顺序，应按接地→承重→后蹬→回收验证。世界角色按约束后实际移动路程推进；捕捉、迷晕与暂停停止步态。图鉴与出售卡片采用独立可见时间，只更新当前卡片，回后台清空上一帧时间。

批量角色清单逐项记录：源素材身份、动作、源帧是否通过、游戏路径、图鉴路径、左右方向、慢速/正常速度、用户反馈。图鉴的 17 条记录不代表 17 套动画已经完成；静态头像、未接入素材和旧基线动物不能写成已验收的当前游戏角色。

## 6. 出售与结算要验证真实数据闭环

出售可以复用图鉴的单张胶囊卡片与左右切换，但数据必须来自已捕捉实例，不是物种清单。卖掉一个实例只移除该实例、增加一次收益，不删除发现记录；最后一个售出后显示空状态。防止重复点击或翻卡时重复交易。

结算固定标题、演出区、真实统计和两个操作槽。失败展示损坏载具及撤离结果；统计来自本局捕捉数、实际出售差额及胶囊消耗，不能虚构奖励。“再次出发”真正销毁旧场景并创建新局，恢复计时、输入和可操作状态；重复查看结算不能再次记账。

## 验收记录与未通过项

- 已观察：手机地图选中高亮、锁定卡片、修正邻行素材泄漏；消息仪表保持圆形且可展开；实际键盘触发上/左/右反弹、受击扣时、下方坠毁和结算重开。
- 源动作问题：逃跑人物候选重复近侧前腿，保留为 rejected；单张撤离姿势不属于完整逃跑动画。
- 用户反馈：仍认为逃跑帧动画缺失、多角色动作不正确；这些项继续修复，不能标记整批认可。
- 技术检查单独记录：模型单测和构建通过只覆盖对应逻辑，不替代源动作及真实游戏播放验收。

项目后续继续迭代时，在本案例追加具体版本和验收范围，不把“代表样本通过”升级成全物种通过。

## 7. 追加：小尺寸清晰度、动作密度和结算站姿

实际错误是：高分辨率源图缩成几十像素的世界角色后，边缘采样稀疏，六个关键姿势的过渡仍明显跳变；结算还把跑步中间帧当站姿，人物脚底高于残车底部，看起来踩在发动机上。这三个问题分别处理，不用整体放大角色掩盖。

- 先读实际画布 backing尺寸/CSS尺寸以及image-rendering，再检查引擎对应版本支持的参数。本例引擎未提供有效的顶层resolution设置，改为2倍backing画布、等比显示缩放，并让相机和HUD边界换算使用同一缩放量。修改后实际验证触控/键盘坐标及回弹；不能只给配置添一个被忽略的字段。
- 1536×1024源图不是POT，在该WebGL路径下不会有完整mipmap过滤。将原像素原尺寸装入POT纹理，开启缩小用的线性mipmap过滤；上传后释放临时GPU源纹理，磁盘原图保留。清晰度以游戏实际大小检查，不以大图预览代替。更大画布与纹理有成本，本例没有声称全设备性能达标。
- 增加帧数应增加接地缓冲、经过支撑脚、摆腿伸膝等真实中间姿势。关键六帧与六个新姿势交错成十二帧；不用重复帧、高FPS或整图镜像冒充补帧。源图偶有换错支撑腿/近臂，需逐帧修正；整张重复修不好时，改单姿势源图并做统一纵横尺度注册。
- 等分格验收仍会漏掉跨格脚趾。本例中某脚越过名义格边13px，下一格视窗误带脚趾。用只读透明度/连通范围定位真实主体区域，修正源矩形与公共画布留边；不是修改角色像素或按每帧包围盒缩放。
- 撤离动画与结算站姿是不同动作。单独制作自然直立、两脚着地的源图，按人物脚底和残车车底共享基线排布；站立成人高度高于坐姿。不能把跑步帧缩小后放在车旁当安全撤离结果。
- 百分比耐久同时用于控制轮盘数字、光圈和受击消息。内部可继续用剩余秒数运算，但面向玩家的消息不再混用秒数。

本轮观察范围：一套世界生物代表样本和一套驾驶员撤离各十二姿势；原生逐帧、慢速、实际显示大小及正常播放检查；真实游戏触发左侧回弹、下方坠毁，观察fall/impact/evacuate/settled阶段；结算独立站姿在手机与默认窗口检查。真实喂食迷晕、撒网后收纳、胶囊卡逐个出售、最后一个卖完的空状态及保留发现记录也已观察。49项现有测试和构建通过，仅证明对应技术检查。

这些是具体实现与观察记录，不表示用户认可全部动画。其他物种仍缺正式动作，三帧砸击也是当前代表样本；后续仍按每物种/每动作验收，不能从十二帧数量推断动作自然或全物种完成。
## 进食链、睡眠与宽屏反馈的补充经验

- 食物按钮有图标不代表世界抛出的物体已经有美术。复用同一绘制PNG，让抛出、落地、拿起及手中的食物能够辨认；投食只扣一次库存。落点应避开车身遮挡，并让拿起帧里的手/果实与地面落点接得上。
- 诱饵效果要由完整状态链驱动：靠近→拿起/咬食/咀嚼/吞咽→犯困撑地侧躺→循环呼吸睡眠。单独的睡眠源姿势替代停住跑步帧；共同角色尺度和地面基线贯穿站立、屈膝与侧躺，睡姿不能按包围盒放大。检查真实源图尺寸与不等距边界，不按出图请求尺寸猜分格。
- 按钮和键盘动作必须走同一个距离、库存、状态判断。先完成吃下与倒下才开放睡眠捕捉收益；浏览图鉴暂停时应冻结同一模拟时钟。已有诱饵对象在遭遇范围内优先保留，避免旁边路过的实体抢走捕捉目标。具体逃脱率、距离、睡眠时长属于当前游戏，不升级为通用规则。
- 视觉动作与按钮语义一致：投网就用网图标及网弹道，不叠第二种投掷物。出售成功反馈必须出现在当前模态卡的可见区域，列出成功、到账增量和当前余额；放到被模态框遮住的HUD不能算玩家看得到。
- 宽屏不使用竖图外的模糊平色条。把同一森林场景向两侧扩展成完整横幅，并采用适合竖屏的原构图；独立车、人物、标题保留纵横比。验证实际宽屏与手机，不能仅查看资产缩略图。

本次验收范围：一个物种的八帧进食、四帧倒下和四帧睡眠呼吸，在森林实机连续播放；模态暂停后继续；睡眠开放捕捉、投食库存只扣一次、远离对象时快捷键不消耗；实际出售卡成功/金币回执；1440×900连续森林和390×844手机构图。53项测试与构建通过，包含旧基线，不能据此声称全物种完成。只同步方法与验收范围，原图、提示词和私人截图留在私有工程。
