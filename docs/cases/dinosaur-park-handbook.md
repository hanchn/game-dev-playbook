# Dinosaur Park：折页手册、分层封面与独立加载

记录日期：2026-10-10。案例使用 Godot 4 原生场景与渲染，目标为手机竖屏。恐龙教育、陆海空同一世界、每页约 7–8 种生物、40 种物种与中英双语属于本项目需求，不能直接升级为其他游戏的通用规则。本文区分可复用方法、源码已有机制与仍待验收的工作。

## 封面和响应式区域要拆成素材与控件

完整概念图用于构图参考。运行时背景、每只角色、前景遮挡、水面、上下纸面装饰分别管理；标题、语言选择、进入按钮、页码和导航使用独立控件。不要把文字与按钮烘焙进整幅图，避免换语言、字体缩放、尺寸调整时只能整体拉伸。

上下区域应输出不含动态文字的装饰素材，再以锚点、容器和九宫格外壳布局；中间场景保持独立。装饰不能挡住按钮点击，触控区和可见图形分别配置。宽度、安全区和纵向空间要独立验证，固定宽高比容器只提供等比例适配，不等于已经适配所有手机。

角色需要局部动作时，将可动部件继续拆开，例如身体与下颌，记录共同画布、原始透明边界、目标边界和旋转枢轴。翼龙上下浮动、海生角色前后漂移与局部水面波纹可以作为轻量封面动效；这些图层动效不能称为恐龙 3D 骨骼动画。

AI 透明图层可能重排构图、扩大主体或改变透明边距。提示词约束无法替代校准：保留固定画布尺寸、测量非透明边界，以数据表记录目标位置和尺度，再在 Godot 里校准。不要默认每张透明图都能用全屏同坐标叠回原画。保留原图、图层、来源、提示词和历史版本。

## 入口、资源完成与页面可见是三个阶段

本案例“立即探索 / Explore Now”只进入轻量书内页，不请求故事世界或恐龙 3D 资源。选定具体故事页后才发起该页加载。对大型内容游戏，可将导航壳、页面内容和单体演绎分别设为加载边界；是否预加载相邻页由实测内存预算决定，不在封面默认加载全部世界。

页面加载应有显式状态：请求 → 资源读取 → 实例化与初始化 → 第一帧可呈现 → 页面就绪；失败则回到可重试状态，不能提前提交页码或隐藏上一个可操作页面。进度来自真实资源读取或可解释的分阶段工作，不用计时器伪造百分比。线程资源完成的信号宜命名为 `resource_loaded`，首帧可展示才称 `page_ready`，避免上层把两个阶段混为一谈。

当前源码 `page_loader.gd` 使用 `ResourceLoader.load_threaded_request` 与 `load_threaded_get_status` 读取进度；其 `page_loaded` 代表 PackedScene 资源完成。`handbook.gd` 接收后实例化，等待 `process_frame` 和 `RenderingServer.frame_post_draw` 再显示页面。这个等待机制不能替代大型 3D 页的材质上传、模型初始化与实际首帧性能验收；页面退出释放节点，也不能直接证明显存和缓存已经回收。

## 加载展示不能反过来增加启动成本

用户要求随机切换恐龙走路序列帧，并显示随机科普小知识。可复用设计是把少量加载动画及知识索引随轻量壳预先打包：同一动画序列内保持固定帧率与循环，换角色在一个合适边界切换，避免每帧随机取图破坏步态。动画帧需有稳定画布、朝向、尺度与接地线；左右腿交替、循环接缝需要看实际播放。

科普条目使用稳定知识 ID，保存正文、语言版本、来源 URL、核实状态和内容版本。随机池只收已核实且适龄条目；没有可用条目时显示普通加载提示，不将角色职业、对白或虚构剧情塞进事实池。后续已接入两套序列帧与三条来源科普，帧边界检查通过；最终步态自然度仍需视觉审校。

## 折页需要真实折痕与纸背

把整页横向缩窄或平移只能表现滑动。折页可把已渲染页面快照贴到多块纸面网格，以独立铰链旋转，分别处理正面、纸背、厚度及角度明暗。输入在过渡期间锁定；结束撤去快照并激活目标页面。不要为了过渡长期同时运行两套大型世界。

当前 `fold_transition.gd` 在 SubViewport 中用 Camera3D、三块独立纸面网格和逐段铰链旋转；已有纸背和侧边厚度。它是封面到轻量内页的离散动画实现，不代表拖动翻页、取消回弹、相邻页首帧等待、方向正确性或所有屏幕比例都已验收。真实折面和用户认为自然的翻书效果是两项不同检查。

## 语言与字体属于交付资源

界面文字独立，语言选择保存到 `user://` 配置文件，启动时读取并验证允许值；验证模式使用独立设置路径，避免覆盖真实用户偏好。双语排版要检查长文案与字号，不能只验证字典里存在英文键。每页内容和语音还需接入同一语言契约。

本次首次使用 SystemFont 时出现空 font 问题，随后改为随包 NotoSansSC 和 NotoSerifSC OFL 字体，当前源码显式加载字体并设置字重。许可文件随字体保留：`OFL.txt`、`NotoSerifSC-OFL.txt`。字体不能只以本机显示正常作为交付依据；后续仍需测量包体和内存，按使用字符考虑 subsetting，并核对许可、保留必要声明与字体回退。不能删除许可来减少包体。

## 当前证据与验证边界

阅读依据：本项目 `scripts/ui/handbook.gd`、`page_loader.gd`、`fold_transition.gd` 与 `docs/游戏架构设计.md`。已有 `cover-runtime-v1.png`、`inside-runtime-v1.png`、`fold-runtime-v1.png` 运行截图；截图可以证明一个视口的输出，不能证明连续动作质量或手机体验。

源码包含 `--verify-cover` 检查：三种语言配置保存、立即探索不增加故事加载请求、明确进入故事页后请求一次、退出清空页面节点和返回封面状态。本文这轮没有重新运行该检查，因此不将读到断言表述为本轮测试通过。已有机制覆盖一个图片预览页，用户提供的 3D 模型尚未接入。

仍需验证：上下装饰独立素材后的响应式布局、中文英文和双语长文本、真实手机安全区与触控热区、折页方向与过渡中断、大型 3D 冷启动和首帧、随机走路图集、科普来源及随机池、加载失败重试、节点与资源回收、字体包体与 subsetting。构建通过、脚本断言或桌面截图都不能代替手机验证。

## 可迁移的验收顺序

1. 锁定一张构图与各独立图层的尺度，再在引擎里检查标题、按钮、上下装饰。
2. 验证入口只打开轻量壳，资源请求计数在真正选页后变化。
3. 验证一个真实内容页的资源进度、初始化、首帧与失败回退，再扩展更多页面。
4. 验证折痕、纸背、方向、取消和边界，再结合加载事务提交页码。
5. 用真实设备记录触控、尺寸、安全区、峰值内存与首帧耗时；记录已验证和未验证项。

## 后续实践更新（2026-10-10）

用户取消翻页动画，改成直接切换场景。不要因早期架构投入而保留已被取消的体验。统一原生按钮组件承担主要CTA、次级、返回和语言选中状态；双语两行需要按字体实际最小高度留出空间，不能只验证按钮边界而忽略子标签溢出。PC采用左右区域，Pad横屏采用三列目的地，手机竖屏采用下方章节内容。桌面尺寸验证不是移动真机测试。

资源库的目录记录不等于已下载模型。此次实际本地只有PNG和Phaser程序鱼群；随后取得目录收录的官方森林免费包，105个glTF及BIN/纹理依赖齐全。Godot场景用显式PackedScene依赖，让线程页面加载包含模型读取。鱼群复用3组×7条、颜色及时间参数进行Godot三维图形适配，不能称为外部骨骼鱼模型。模型风格与封面差异必须单独评估。

原始腕龙抠图中尾巴从身体前侧错误连接，不能仅用位移修正解剖；保留v1，生成修正v2并重新测量透明边界。霸王龙生成下颌变形时，恢复原图像素UV，采用极小刚性旋转。3D页面被根层不透明ColorRect遮挡时，应在显示页面时隐藏导航底色，并在返回恢复，而不是误判模型没有加载。
