# 蚯蚓平台冒险：连续蒙皮、有限追击与完整 UI

2026-10-13，来自实际 [worm-run](https://github.com/hanchn/worm-run) 集成。复用已有动物骨骼与 seedHash/ChunkCache，横版通道、身体碰撞、树枝平台和导航按游戏适配。vendor快照逐文件记录SHA，与当前仓库不同的文件如实记录，不把目录收藏当实现。

## 失败与修复

- 回头头没了、反向成团：旧关节方向让头撞上旧身体，绘图又覆盖脸。平地整链重定向，连续PNG按尾到头画，头前两节维持切线，不叠硬边头贴片；必须看反向和跳跃姿势。
- 竖井仍成团：180°整链转入泥墙，独立最近点纠正把尾段压在同一点。后脑留两个关节，沿真实通道图找足够长的后方路径，再采样身体。不能只限制头，回归检查非邻接节段间距和整体跨度，并看同姿势运行图。
- 被吃很久才变短：减耐久等计时耗尽不等于咬断。命中当帧分段、掉一命，保留较长前段、重置耐久、保护3秒。尾段先离开切口12像素再下落，避免看不出分开。石头、玻璃和摔落另按耐久受伤。
- 隔墙发现但不抓：决策、寻路、移动分离，地底天敌沿通道绕行并走真实洞口。攻击也要检查可达线，不能隔泥墙咬。
- 一直追吃：追击累计时钟不能在准备/攻击/恢复间重置。170感应、240脱离、5秒超时、20秒冷却；吃到立即撤退。冷却不画感叹号。
- 树间跳不到：先核对跳高/枝距/单向平台，再查隐藏y钳制。旧y>=60截断高枝跳；改世界范围及竖向相机。低层双侧枝让中层下落有落点，短暂忽略原平台后恢复下层碰撞。
- 鸡鸟只有移动：鸡用重力短跳、最低枝落脚和骨骼flap；鸟每屏单实例，长停高枝后换枝，翅膀飞行、俯冲俯仰、抓取伸爪、啄食动头，吃后回枝。
- 跳跃露褐色空带：世界cameraY变了，背景底线/土层填充仍固定G。统一所有层cameraY并留覆盖余量。
- 石头像椭圆：碰撞椭圆可保留，视觉用明确岩面、苔藓、层理PNG；大小两档，大石侧边挡步行，顶面可跳上，身体跟随考虑石面。
- UI线框/按钮变形：独立木叶纸心九切边框、按下按钮和木槽进度，文字数字DOM；注册alpha边界后用原比例contain。首页、暂停、结算、确认、错误、加载逐页看；用户取消焦点光圈。
- 进度填充出槽：contain实际图框比父容器小，fill却按整个容器定位。木槽/fill共享注册图像框和aspect-ratio，内槽再百分比定位，必须查看真正的中间加载状态。

## 场景与互动

routes/decor/environment独立seed通道，加载次序不改地形。3块换地区，花园/森林/瀑布/金秋/雪林/沙漠循环；天气35秒周期使用游戏时钟、暂停冻结。蓝鸟/知更鸟/麻雀采用独立分件原图，其他角色保留骨骼切季节材质，不把调色称为新物种。

雨雪减速、阵风影响空中与报纸、瀑布18秒水流周期；靴子攀爬/躲藏、罐子可推可站、报纸踏过飘动、破瓶口伤害。大洞鸡概率探啄按seed+感应周期取样，不能逐帧抽到必然发生。
